# 06 配套资料

> 本目录＝治理体系的 **配套资料层（公开）**：存放各书配套的**第三方源件（原书 PDF）**与**整理文本（02 层提取/结构化副本）**。
> 组织方式：**一本书一个文件夹**，与 `05_整理书籍/`（书稿产品）中的同名书文件夹一一对应。

## 结构

```
06_配套资料/
└── 01_小六壬通识/                    ← 对应 05_整理书籍/01_小六壬通识/
    ├── 源件（第三方原书）/            ← 原始 PDF 源件（供对照查看）
    └── 文本提取（02层）/              ← 02 初步处理层的文本提取/结构化副本（供在线直接阅读）
```

## 说明

- **定位**：本层与 04 研究成品、05 整编书籍同属**公开层**（随 git 上传远端）；源件与文本**不属于书稿正文**，不进入《小六壬通识》合订本与 PDF。
- **来源与版权**：源件均为公开或整理所得的第三方/古籍材料，只作研究性引用与对照；如权利人认为公开不妥，请联系删除。
- **文本性质**：`文本提取（02层）/` 为**机械加工**产物（编码统一、去壳、文本化、索引化），不含解释与改写；疑似识别误字以 `[?]` 标注。
- **留档**：源件同时存于 01 原始层（本地、只读）；完整 02 层（含逐页文本、审计记录、脚本）在本地治理层 `02_初步处理/`。

*各书细则见其文件夹内 README。本层随治理体系维护。*
