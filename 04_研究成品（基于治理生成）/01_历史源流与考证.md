# 小六壬 · 历史源流与考证

> 本文综合"搜狐·星台君《正经严肃的小六壬简史》"（2017）、香港"乐命堂·潘乐德《小六壬的前世今生》系列"（2024）、维基百科"六曜"条目、维基文库《钦定协纪辨方书》等资料整理。凡属研究者个人观点者，均已注明。

## 一、名称小释

| 名称 | 说明 |
|---|---|
| 小六壬 | 今日常用名。最迟在清朝乾隆年间已见于官方文献（《协纪辨方书》："上兀下兀乃俗传小六壬之留连赤口日"）。 |
| 六壬时课 | 《玉匣记》（《增补许真君万全玉匣记》）中所载名称："李淳风六壬时课"。 |
| 诸葛马前课 | 民间俗称。一说诸葛亮行军时在马前掐指起课，故称"马前课"。 |
| 六兀轮经 / 六轮经 / 六轮兀法 | 与六曜择日、上兀下兀日同源的一支，常与"小六壬"并提。 |
| 掐指一算 / 掐指神通 | 民间口传俗称。 |

**关于"六壬"本义**：正统"六壬"（大六壬）之名，通行解释有三类：①河图"天一生水，地六成之"，壬为阳水；②六十甲子中**壬干有六个**（壬申、壬午、壬辰、壬寅、壬子、壬戌），故名"六壬"；③《周易》"乾"卦纳甲（奇门称遁甲）、外卦纳六壬等说法（《壬学琐记》辑录诸说）。大六壬与太乙、奇门并称"三式"，"学会大六壬，来人不用问"。

**关键考证意见**：研究者星台君明确指出——"真正研究过大六壬或天罡掌诀或走马六壬的人都知道，**小六壬实质上和作为式法类的六壬完全没有关系**"，其称"六壬"更多是挂名依附。另有学者潘乐德主张小六壬是"大六壬的後裔"，继承了天将系统（十二神将浓缩为六神）、三传法（对应三宫断法）与"判断眼下是否最佳状态"的占算思维（详见第五节）。

## 二、两种祖师传说

### 1. 传说一：诸葛亮（181—234）
- 称小六壬为诸葛亮行军前测算吉凶所创，故名"诸葛马前课"。
- 苏轼《东坡志林》等文献中有诸葛亮"马前课"（谶诗）传说，但那是**十四课谶诗**（预言朝代兴衰），与掐指起课的"小六壬"是两回事（参见 03 人物篇"诸葛亮"条目）。
- 学术意见："查无实据"（潘乐德）、"伪托"（星台君、乾隆官方亦如此看待同类托名）。

### 2. 传说二：李淳风（602—670）
- 称小六壬出自唐代李淳风《六壬时课》。李淳风，岐州雍人（今陕西），唐代天文历法家、数学家，与袁天罡合著《推背图》（传说）、著《乙巳占》《宅经》等，被后世六壬家尊为祖师之一。
- 学术意见：**原版无从考证**，现存皆为民间手抄本（江春义）；星台君认为"李淳风的六壬书目并未传世，小六壬也非李淳风所创，后世术数书的伪托，令淳风背锅不浅"。也就是说，《玉匣记》等书在"六壬时课"前冠以"李淳风"之名，是明清术数书常见的托名手法。

### 3. 传说三：东方朔（今人异说，孤例）
- 有现代小六壬网站（如"道传小六壬在线排盘"）称此法"相传为东方朔所创，亦有说法与诸葛亮相关"。
- 此说在古籍与主流整理中**找不到依据**，属于当代网站文案中的孤例异说，录以备考，不建议采信。

> 小结：**诸葛亮、李淳风均属后人托名**，是目前严肃整理者的基本共识；"东方朔说"为当代孤例，更无依据。小六壬真正可考的源头在唐末五代至宋代的择日/历注传统与民间掌诀。

## 三、分期考证

### 3.1 唐末五代：雏形（约10世纪）
- 现存线索之一：敦煌占卜文书 **P.3803《咏黄道诀》** 中有一处名为**《龙母决》**的记载，其轮布规律为：
  - 正月、七月——龙母；二月、八月——连；三月、九月——龙安；四月、十月——空亡；五月、十一月——龙德；六月、十二月——四煞。
  - 此规律"与小六壬完全相同"，名字上也有相似处（"空亡"等），但无吉凶属性和占辞，研究者认为**是小六壬的雏形之一**。
- 敦煌占卜文书多出自10世纪左右五代时期"唐时阴阳生"之手，带佛道交融的民俗背景。
- 潘乐德指出：唐初吕才所撰《大唐阴阳书》及其他曆注皆无"大安"等六曜痕迹，故**六曜在唐朝应尚未出现**；但六曜体系"最早应形成于唐末五代时期"，主要用于**选择吉凶日子**（择日）。

### 3.2 宋代：上兀下兀日与六轮兀法（关键链条）
- 宋代流行以"兀"择日，**上兀、下兀日**名声最大——因其凶险："上兀犹自可，下兀急如火"；犯之忌上官、赴任、临政、出行，百事皆忌。
- 元初《居家必用事类全集》（内容多定稿于宋）载：
  - "其法有六轮兀、本命兀、九宫兀、川兀、京兀、传神兀、寅午戌兀、十二宫兀、坎离兀、九元兀、顺逆兀、秘要兀、五位兀、大小月兀，何啻二十余家，多是穿凿不经。"
  - "其间惟六轮一兀，乃沈存中作内翰时修元丰历，阁下寻出用之。最验。今台馆中率用此法。"——即北宋**沈括**（沈存中）在修《元丰历》（约1078—1085）时检验二十余家兀法，认定**六轮兀法最灵**，此后台馆沿用、渐传民间。
  - "又有本命兀者，乃川本。各随人本命，布六位，以求吉凶，亦非泛然用兀之比。"——**本命兀法**是上兀下兀日的"私人定制版"，用于推算个人命运。
- 六轮经兀法歌诀（《居家必用事类全集》）："六轮经中有兀星，阳乾阴巽顺行轮。乾号六白为印绶，坎宫一白天禄星。艮宫八白为左辅，九紫离宫右弼星。巽宫四禄为上兀，坤宫一黑下兀星。震三兑七不轮转，万事逢兀必有迍。年上起月月起日，此法用之通神明。"
- 宋人笔记中的著名故事：官员**丁顾言**赴蜀上任前遇老僧，被告知上任之日是"兀日，不可视事"，他不听，月余果然因事免官，遂从僧学此法（见《王氏谈录》，又《协纪辨方书》引"宋王明清谈录"）。《续墨客挥犀》亦载"仕宦多忌，兀日不赴官"，并推测"兀"或为"亢"字之误。
- **原理揭示（清代）**：《协纪辨方书》一语道破上兀下兀日＝小六壬的"留连、赤口日"：
  - "阳年正月初一日起小吉，阴年正月初一日起留连，按日顺数"——按此排列，当日为**留连即上兀日，为赤口即下兀日**。
  - 值得注意的是：上兀下兀只忌留连、赤口，**完全不忌空亡**——与小六壬"空亡大凶"不同，说明宋时六卦象义**尚未定型**（潘乐德语）。

### 3.3 元、明：定名与定型
- 元：星台君称"黑水城文献中已出现今日现行的小六壬内容"。**备注**：独立检索所见黑水城出土占卜文献主要为六壬金口诀类（如 TK172《六壬课秘诀》，学界考为金口诀）、易占、时日宜忌、禄命等，未见明确公布"大安—空亡"六曜式小六壬文书；此说**待进一步核实**，引用时宜谨慎。
- **《事林广记》**（南宋末元初陈元靓编，后世多有增补）所载六曜为"**大安、留连、速喜、赤口、小吉、空亡**"——今日定名已见。
- **《玉匣记》**：全书"出于明朝宣德年间"，为道教宜忌选择择日之书，卷首序言托名东晋许真君（许逊），署"宣德八年（1433年）龙集癸丑夏四月朔旦，耕笔斋吴子谨书序"。星台君根据内容风貌（仅以六十甲子论神、不避戊日）判断其底本"颇有宋前道教选择书的风貌，应为隋唐时期道士的作品"。
- **明清白话小说中的小六壬痕迹**（说明当时已很风行）：
  - 明末清初西周生《醒世姻缘传》第七十六回："街上一个打路庄板的瞎子走过。相大舅叫他进来，与狄希陈起课，说是'速喜'，时下就到。"
  - 明末清初褚人获《隋唐演义》第七回：妇人替秦叔宝起课，"卦名速喜。书上说得好：'速喜心偏急，来人不肯忙。'"
  - 清 曹雪芹《红楼梦》第四十二回：凤姐之女发热，"依我说，给她瞧瞧崇书本子……"平儿拿出《玉匣记》，彩明念道"八月廿五日病者，东南方得之，遇见花神……"（可见《玉匣记》在清代民俗中的地位）。
- 星台君判断：**现行小六壬体系至迟在明末已定型**，并存在多种歌诀传承；明末清初小六壬在民间已广泛传播。
- **传入日本**：约14世纪（镰仓时代末至室町时代）六曜历注传入日本（详见第四节）。

### 3.4 清代：官方文献中的"小六壬"
- 《协纪辨方书》（钦定，乾隆四年/1739年敕撰，庄亲王允禄、梅瑴成、何国宗等奉敕编，历时三年多，收入《四库全书》）"辨讹"一卷痛加批评：
  - "上兀下兀乃俗传**小六壬**之留连赤口日，阳年正月初一日起小吉，阴年正月初一日起留连，按日顺数，**尤为荒陋**……应请一并删去。"（乾隆四年七月二十七日奏文）
  - 该书还主张删除"男女合婚、嫁娶大小利月及诸**妄托许真君之《玉匣记》**等"。
  - 意义：这是"小六壬"之名见于**官方文献**的早期确证之一；也说明当时它已被官方视为荒陋杂术。
- **《增补许真君万全玉匣记》**：今通行本是以原《玉匣记》为开篇、博采清光绪年间通书择吉内容而成的民用通书；**光绪壬午（1882）素云道人刘诚印发心重刻**、**光绪癸未（1883）芷亭道人王裕芬作跋**。小六壬（李淳风六壬时课）借助此书在民间广泛流传。
- 民间传播特征：通书、小说继续传播小六壬；少数隐逸之士深研其术而秘不外传。

### 3.5 近现代与当代（1980s—今）
据星台君梳理（2017）：
- **1980s—1990s（蒙昧期）**：易学复兴，许多人拿《玉匣记》当"天书"看，学会李淳风六壬时课后也只是偶尔占玩。
- **1990s—2000**：少数易界人士开始关注小六壬，如**霍斐然、殷少卿**等。
- **2004年前后**：以**霍斐然《小六壬预测法》的完整发表**为标志，小六壬"步入易学界大雅之堂"。
- **2004—2008**：网上开始出现小六壬资料；较早出山的有**江春义**，稍后有**邵一尘**等。
- **2008—2010**：**邵一尘的道传（道家）小六壬体系**开始面世；江春义、华山等派也先后出山。
- **2010—至今**：道传小六壬资料网络扩散，"人手一份道传小六壬PDF"；智能手机、网盘、短视频时代加速传播；培训班、排盘系统、APP大量出现——**近20年的发展远超过去两千年**，同时"小六界乱象丛生"：拼凑资料自成一派、10分钟速成者从事商业占卜、忽悠未成年人等。
- 现代整理与研究：2017年搜狐"星台君"发表《正经严肃的小六壬简史》；2024年香港潘乐德（乐命堂）发表《小六壬的前世今生》系列，从文献与择日学角度梳理源流（其一为"与大六壬的承传关系"，其二为"梦回大宋 择日寻根"，另有多篇，如"密宗占星竟然是远祖""掌诀可以推算鬼神病"）。
- 台湾、香港：台湾有**馥灵之钥**等做"身世考证＋互动起课"；香港有**潘乐德（乐命堂）**"小六壬占卜深度学"课程、**陈定帮**等做教学视频；港澳台整体热度不及内地（潘乐德观察）。

## 四、与日本"六曜"的渊源

> 日本史料年表（1688年《头书长历》、江户《大离书》序列、幕末普及与明治禁令）与现行算法，详见《19_日本六曜源流考（大离书·六辉）》。

**六曜**（又称孔明六曜星、六輝）是中国传统历法中的注文，标示每日吉凶；传入日本后广泛流行，在中国则日渐式微。

### 4.1 传入与演变
- 约**14世纪**（镰仓时代末期至室町时代）传入日本。
- 名称演变：
  - 《大离书》（江户时期，不同资料记载微异）：即吉、共引、周吉、虚亡、泰安、赤口；或作：泰安、流连、则吉、赤口、周吉、虚亡。
  - 19世纪初演变为今日之名：**先胜、友引、先负、佛灭、大安、赤口**（顺序与吉凶意义与中国清代定型的小六壬有所不同）。
- 日本室町时期传入时主要用于**历书编排**（不似近代中国那样用于占卜）；幕末民间开始在日历上标注六曜；明治时代政府禁止迷信注文，但六曜因"未被归类为迷信"而保留；二战后广为流传。
- 用途：结婚选"大安"、葬礼避"友引"等；民间信仰按字面理解：友引日办丧事会"把朋友也引到黄泉"云云。早年六曜吉凶多与**赌博**相关（赌徒用来决定是否下注），现今日本国营博彩机构印制的彩票上也会印六曜。

### 4.2 日本现行六曜速查
| 六曜 | 含义（一般解釈） |
|---|---|
| 先胜 | "抢先者胜"；急事吉，午前吉、午后凶 |
| 友引 | "引来朋友"；喜事吉，忌丧事；朝夕吉、正午凶 |
| 先负 | "抢先者负"；宜静守、谨慎；午前凶、午后吉 |
| 佛灭 | 万事凶（葬礼法事无妨） |
| 大安 | 万事大吉，尤宜婚礼 |
| 赤口 | 凶日，祝事大凶；注意火与刃物；正午吉、朝夕凶 |

### 4.3 日本六曜的推算（现行）
将旧历的**月份＋日期**相加：
- 能被6整除 → 大安；
- 余1 → 赤口；余2 → 先胜；余3 → 友引；余4 → 先负；余5 → 佛灭。
- 例：旧历正月一日＝1+1=2，余2 → 先胜；二月一日＝3 → 友引；……闰月排列与前月相同。

### 4.4 版本对照
《事林广记》所载六曜："大安、留连、速喜、赤口、小吉、空亡"（与中国小六壬一致）；日本《大离书》则作"泰安/流连/则吉/赤口/周吉/虚亡"等；口传中又讹变为"大安/友引/先胜/赤口/先负/佛灭"，最终形成现今顺序。

## 五、与印度/密教占星的关系（潘乐德观点）

- 潘乐德指出：日本东密相关典籍《文殊师利菩萨及诸仙所说吉凶时日善恶宿曜经》（简称《宿曜经》）中只有日月五星的"七曜"，没有"大安"等六曜，故**六曜不早于唐代**。
- 但《宿曜经》中有"七宿"（二十七宿直日）概念，其"意义乃至名字都与六曜类似"，故六曜**或可视作《宿曜经》内容的一种简化**，具有天文择日元素。
- 潘乐德在另一篇文章中进一步称"密宗占星竟然是远祖"（标题语）。
- ⚠️ 事实订正：《宿曜经》**由唐代不空三藏译出（759年）**，天文历法学者**杨景风**作注；**空海（774—835）是将其传入日本的关键人物**（806年归国后弘传密教及宿曜道），并非"翻译者"。潘文中"空海和尚翻译的《宿曜经》"一语属误记，引用时宜加辨析。
- 近代日本仍流行基于《宿曜经》的"宿曜占星"（二十七宿关系占断等）。

## 七、学术悬案与不同观点（提醒）

1. **名称来源**：
   - 一说"小六壬"之名或来自"小六轮"（六轮），"传着传着就变味成小六壬"（星台君文中转述此说，认为有道理）；
   - 另一说（维基百科"六曜"条）：因六宫"大安、留连、速喜、赤口、小吉、空亡"与六壬式十二天将中的六神"青龙、玄武、朱雀、白虎、六合、勾陈"一一对应，"**可能是称为六壬时课或小六壬的原因**"。
2. **与小六壬无关还是后裔**：
   - 星台君：小六壬与式法类六壬"完全没有关系"，只是挂名。
   - 潘乐德：小六壬承袭了大六壬的三大基因（六神／天将系统、三宫≈三传、占算思维），可视为"大六壬的后裔"。
   - 两说并存，角度不同：一说重文献与体系属性，一说重技法与思维结构。
3. **《玉匣记》成书年代**：序署1433年；但星台君据内容判断底本可能早至隋唐。
4. **宋代象义未定型**：上兀下兀日只忌留连/赤口、不忌空亡，说明"空亡大凶"是较晚才固定的。
5. **六轮经≠小六壬真本**：清代江浙县志中的"六轮经"多用于丧葬"回煞/批书"，与占卜的小六壬并非同一物，注意区分。
