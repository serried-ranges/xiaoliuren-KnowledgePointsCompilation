# 小六壬 · 道传卜法卷系统化（体用 · 具象 · 应期）

> 本文把道传（道家小六壬）公开的"卜法卷"内容**系统化、公式化**，整理成可操作的断卦手册：体用判定、三宫具象推演、应期计算、转太极三类、六大分类占流程卡。
> 依据：itmkk《道家小六壬》（邵一尘体系）与《小六壬入门＋分类预测》整理文。凡原文存在矛盾或疑误处，已在校勘注中标记。

---

## 一、体系地图（卜法卷结构）

```
基础篇：六神总论 → 掌诀定位 → 五行生克 → 六亲 → 体用 → 六神定义/干支/数字
通则篇：三盘（天地人）→ 类象 → 干支 → 数应 → 神煞十二宫 → 体用
明卦篇：成败 → 婚情 → 寻物 → 罹病 → 面相 → 风水 → 天象
应期篇：远者观季节地支，近者参体用三宫
运技篇：转太极（六亲/事件/神煞） → 三宫具象
```

核心盘式：**三盘**（月=天盘/起因，日=地盘/经过，时=人盘/结果）＋**落宫为体、时辰为用**。

## 二、体用判定（公式化）

### 2.1 判定流程

```
Step 1  取体：落宫（时宫）＝体（自身状态/结果）
Step 2  取用：时辰＝用（未来趋势/外部影响）
Step 3  判五行关系（体五行 vs 时辰五行）
Step 4  查表定向：
        用生体 → 大吉（贵人外力）
        体克用 → 小吉（主动可成，"克出"）
        体用比助（阴阳异）→ 吉（合作互助）
        体生用 → 小凶（消耗付出，"生出"）
        用克体 → 大凶（受阻，"克入"）
        体用比劫（阴阳同）→ 凶（竞争小人）
Step 5  附注：若无后续发展之事，体用改读为"外部环境对自身的影响"
```

### 2.2 示例演算

| 落宫 | 时辰 | 关系 | 断 |
|---|---|---|---|
| 速喜（火） | 亥时（水） | 水克火：**用克体** | 不利，事受阻 |
| 速喜（火） | 卯时（木） | 木生火：**用生体** | 有利，贵人相助 |
| 赤口（阳金） | 酉时（阴金） | 同五行、阴阳异：**比助** | 吉，朋友帮手 |
| 赤口（阳金） | 申时（阳金） | 同五行、阴阳同：**比劫** | 凶，竞争内耗 |

### 2.3 关键原则
- 三宫生克（天-地-人之间）**不改变落宫本身的吉凶**，只表示"助/制"的过程（"生者为顺助，克者为制转，同者为争复，异者为扶孤"）。
- 体用是**趋势修正器**，不是吉凶的第一来源；先看落宫吉凶，再加体用。

## 三、三宫具象法（步骤化）

> 道传高级技法：由三宫阴阳推出一卦（八卦），再与盘位论生克，得出隐藏细节。

### 3.1 推演步骤

```
Step 1  定阴阳：大安/速喜/小吉＝阳；留连/赤口/空亡＝阴
Step 2  取盘序（三宫取用顺序因盘而异）：
        天盘：以"人-天-地"之序（天居中央）
        地盘：以"天-地-人"之序（地居中央）
        人盘：以"天-人-地"之序（人居中央）
Step 3  转爻成卦（阳爻＝—，阴爻＝--）：
        三阳（———）＝乾
        三阴（------）＝坤
        阴阴阳（☳，仰盂）＝震
        阳阴阴（☶，覆碗）＝艮
        阳阴阳（☲，中虚）＝离
        阴阳阴（☵，中满）＝坎
        阴阳阳（☱，上缺）＝兑
        阳阳阴（☴，下断）＝巽  ← 校勘注
Step 4  论天盘八卦与三宫的五行生克：
        克出 / 生出 / 克内 / 生内 / 同
Step 5  依生克"复转三宫"，得出该盘具象
Step 6  地盘、人盘同理各得具象 → 合断细节
```

**校勘注**：整理原文此处作"阳阴阴下断者为巽"——与艮（阳阴阴覆碗）重复，疑为笔误；按卦象巽☴当为"**阳阳阴·下断**"。使用时以标准八卦卦画为准。

### 3.2 使用提醒
- 具象是"在基本吉凶之上的细化"，**不可推翻基础卦论**（"具象……基其首宗卦论之上，不可另出"）。
- 属高级技法，初学者可先跳过。

## 四、应期计算（公式化）

### 4.1 远事公式（问数月/年之外）

```
Step 1  落宫定季节/地支月（取值表）：
        大安 → 春 → 寅卯（辰）月
        留连 → 四季/长夏 → 辰戌丑未月（一说辰巳月）
        速喜 → 夏 → 巳午（未）月
        赤口 → 秋 → 申酉（戌）月
        小吉 → 冬 → 亥子（丑）月
        空亡 → 冬春 → 丑寅月（一说辰戌月）
Step 2  叠六神数应（大安1/4/5；留连2/7/8；速喜3/6/9；赤口4/1/2；小吉5/3/8；空亡6/5/10）
Step 3  按问卦者男女、事情性质，取阴阳奇偶、上下浮动
Step 4  用体用生克修正快慢远近
Step 5  输出为"范围"而非精确日期
```

**校勘注**：原文对留连、空亡的月份归属有两种表述（留连"辰巳月"与"辰戌丑未月"；空亡"丑寅月"与"辰戌月"），说明该体系内部亦未完全统一——建议固定一种用法并标注。

### 4.2 近事公式（问数日/时辰之内）
- 寻三宫生克之理（生者缓、克者急）＋体用远近＋落宫数应，直接推断。

### 4.3 婚期特例公式

```
Step 1  明卦主十二生肖
Step 2  依六亲内外生克：男者"克出"、女者"克内"
Step 3  寻姻缘对应六神
Step 4  合体用生克 + 落宫数应
Step 5  取年时干支五行内外 → 定何年何期
```

## 五、转太极三类（公式化）

| 类型 | 什么时候用 | 方法 | 示例 |
|---|---|---|---|
| **六亲转太极** | 问六亲中人 | 以"我"为太极，按生克转出对应六亲 | 落宫示"女"，天宫＝男（姻缘） |
| **事件转太极** | 追问事情相关方 | 按事件前后左右关系转 | 问"项目赚几许"→转出"生项目者＝获益方" |
| **神煞转太极** | 急变之事、非六亲/非事件 | 以六神煞类象转化 | 青龙→事业/学业；朱雀→文书/婚喜 |

**规则**："据需而转，无问者勿动，无需者勿转。"

## 六、六大分类占流程卡

### 6.1 成败占
```
① 首观落宫六神 → 该事基本状态（安/拖/快/凶/和/空）
② 事有首尾 → 立三才：生者为顺助、克者为制转、同者为争复、异者为扶孤
③ 合盘位与六神类象 → 综合下断
```

### 6.2 婚情占
```
① 人宫为太极（核心卦果）：成否、分否、羡否、合否
② 天宫：缘分、初识/初成之期、未婚对象的"对方"
   （已婚者改用六亲转"配偶"）
③ 地宫：经过、二人居所、行为、成/绝之因
④ 关系细断：天人＝缘分深浅；地人＝亲友同僚的影响
⑤ 婚后/已婚：以六亲转之
```

### 6.3 寻物占
```
① 先问"能不能寻回"：落宫示是非
② 若可寻：天宫＝物之态/所居；地宫＝物之变/方位所趋；人宫＝物之向/所寻
③ 进阶"转地宫太极"：以地宫为太极点，按五行同转推失物确切位置
④ 统摄六神意象 + 五行类象（颜色、容器、环境）落位
```

### 6.4 罹病占
```
① 分盘：天＝诱因（外感六淫/内伤七情）；地＝病之来去、轻重变化；人＝何病、结果
② 五行配脏腑（木肝胆、火心小肠、土脾胃、金肺大肠、水肾膀胱三焦）
③ 结合奇恒之腑（脑、髓、骨、脉、胆、女子胞）类象
④ 六神五行修正（如"大安可论首、四肢；速喜可论心脑；小吉、留连可论女子胞"）
※ 医疗问题应以就医为准，占测仅作文化整理记录。
```

### 6.5 面相占
```
① 三宫应三停：天宫＝上停（发际—印堂）；地宫＝中停（印堂—鼻准）；人宫＝下停（人中—地阁）
② 以落宫（人宫）为基础，观形神隆陷
③ 五行五性：木主细瘦、火主尖露、金主方正、水主圆肥、土主浊厚
```

### 6.6 风水占
```
① 定向：天宫＝向，地宫＝座，人宫＝入气流动位
② 宅外八方：以"天宫五行"为起点、按"时辰五行"旋转，重排八宫方位
③ 宅内排布：以"人宫气位五行"为起点、按"时辰五行"旋转
④ 据类象观物断吉凶
```

## 七、操作化建议（整理者按）

1. **断卦顺序固定化**：起课 → 三盘 → 落宫吉凶 → 体用 → 生克 → 数应/应期 → （必要时）转太极/具象。
2. **公式的边界**：本文所有"公式"都是对民间口诀的结构化转写，**不是数学定理**；算法固定但取象灵活。
3. **一致性优先**：留连/空亡月份、巽卦卦画等处原文有歧，练习时**固定一套**，避免同一卦两种算法。
4. **输出纪律**：应期给区间、吉凶讲趋势、疾病建议就医——与现代占卜伦理一致。
