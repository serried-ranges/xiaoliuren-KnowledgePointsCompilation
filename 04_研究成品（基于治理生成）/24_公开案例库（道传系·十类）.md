## 二、道传系案例详录

### 案例1｜婚期（邵一尘原文）
- **问**：朋友的朋友当场考问"你能算出我什么时候结的婚吗？"（原则性问题本可婉拒，对方无刁难意，遂试之。）
- **课**：小六壬卜卦，**落大安宫**。
- **断**：你是在今年（2011年）**4月5日**结的婚。对方大为惊讶。
- **理由**：
  1. 大安排位1 → 今年为"11年"，符合1数（前推10年则年龄不合）；
  2. 结婚为**阴阳之合** → 取大安"4、5"两数并用；
  3. 以男为主、4数排前取月、5数取日 → 4月5日（"15日"虽可能但概率小，取概率大者）；
  4. 历法：一般取农历；若对方以阳历发问则取阳历。
- **方法要点**：先定吉凶→定时间粒度（年/月/日）→取数与概率→当机立断。

### 案例2｜考试名次与分数（邵一尘原文·取数法演示）
- **名次**：落大安 → 先取排位1为第一名；若**前两宫较差**（说明成绩一般但发挥好），改取两数组合：男孩14、女孩15（震长男取4、巽长女取5）。
- **分数**：落大安、语境为"分数"（十几分不可能） → 用**隐藏排位数7**：男孩断74分、女孩75分。
- **要点**：明数与隐藏数的切换逻辑——"数字不是固定的，要根据实际情况而定"。

### 案例3｜货款应期（邵一尘原文·四分支断法）
- **问**：对方的货款几天能到？
- **课**：落**速喜**。
- **断**：3天。
- **理由**：所问涉及钱财，事件五行属金；速喜为离火；火克金＝收入之象；3为离火本位数（同时是排位数与先天卦数），故取3。
- **分支同题**：留连→"暂时不会到账，至少要四五个月"；赤口→"会有纠纷，可能通过官司或争吵才能拿到"；空亡→"不一定能拿到，让他马上查对方公司有没有问题"。
- **原文提醒**："就算别人问的是数字性问题，你也要**先以卦的吉凶论事，然后才看数字**。"

### 案例4｜快递应期（四明居士）
- **问**：快递什么时候能到？
- **课**：落**大安**。
- **断**：取"1·4·5"数组合判到达时间。
- **步骤**（原文）：①判断数字准不准确；②判断起课有无错误（第一时间起课一般不会错，不要故意起课）；③下结论。

### 案例5｜三宫具象演示（四明居士）
- **原卦**：速喜 速喜 空亡（申时）。
- **演示**：把天盘速喜放中间具象 →"阴阳阳为兑卦"；兑卦金被天宫速喜（火）克 → 全克一遍 → 得"赤口 赤口 小吉"等展开（详见《21》§6.2）。
- **性质**：网络公开的个人演示，步骤细节待以《卜法浅要通则》原文核。

### 案例6｜应期取数例"447"（网络转录）
- **课**：心动起卦，报数447，申时 → 赤口-大安-大安；两金克人宫大安，断"必跳"。
- **取数**：大安取1/4/5；对方为女孩取5；5分钟后应验。
- **备注**：原案例语境从简（转录自网络整理文），仅存**方法演示**价值。

### 案例7｜寻物（网络）
- **课**：速喜-留连-空亡。
- **断**：地宫定方位 → 东南（留连属四角之一）；留连＝阴暗处、空亡＝盒子、速喜＝红色/网络相关物 → 实际在**一个盒子里**找到。

### 案例8｜感情（网络）
- **课**：子时一女测感情 → 速喜-速喜-留连-子时。
- **断**：天宫速喜为火，"克天宫的年份为在一起的时间"——当年壬寅年，水克火 → **当年在一起**；留连主担忧而非停滞；天、地宫都生人宫 → 女方占优势；对方速喜"三分钟热度"，谨防不持久。
- **反馈**：问者怕异国恋出矛盾，欲知注意事项。

### 案例9｜健康与学业（网络·小例节选）
- **头伤**：赤口-大安-速喜-申时 → 断"头伤"（赤口克大安＝伤克头，速喜为血）。
- **呼吸**：赤口-留连-留连-未时 → 呼吸问题（赤口为呼吸、留连为难受），兼消化不好。
- **专升本·不中**：大安-速喜-小吉-酉时 → 人宫克地、生天，不得天时地利；小吉（智慧）被克泄严重 → 不能上。
- **专升本·中**：大安-赤口-赤口-酉时 → 两赤口竞争大；克天宫为"通关之象" → 过。

## 四、案例使用说明与方法论

1. **性质提示**：以上全部为**自证型案例**（发布者自选、自录、自述反馈），存在选择性展示；学习其**方法链**即可，勿当"准确率证据"。
2. **复盘模板**：背景→起课（年/月/日/时或报数）→三宫或装卦→用神/体用→断语→反馈→**哪一步是方法、哪一步是推理、哪一步是感觉**。
3. **取数练习**：先从应期类（快递、货款、婚期）练"明数/隐藏数/合数"；再从关系类（感情、离婚）练体用与六亲。
4. **素材缺口与扩展**：
   - 公开缺：官非、开店、比赛、面相、风水、天象、来意（道传系）——可关注公众号"陈君安"（获授权案例）与资源站中的案例合集；
   - 江氏系：教程40—120＋几乎每篇一例（官网可查），是**现成最大公开案例池**；
   - 建议自行建立"案例卡"（本库即模板），注明体系标签（传统/道传/江氏），避免混记。
