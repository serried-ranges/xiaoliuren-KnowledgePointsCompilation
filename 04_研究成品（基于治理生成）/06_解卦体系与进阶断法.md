# 小六壬 · 解卦体系与进阶断法

> 起课只完成一半，关键在于"怎么断"。本文汇总：①传统三宫断法；②道传（道家小六壬）体系；③江氏小六壬体系；④进阶技法（活六神、地支择法、地支关系、墓库应期）；⑤实战案例。

---

## 一、断卦总纲：四步法

1. **定吉凶**：先看最终落宫（时宫）的六神属性——大安/速喜/小吉偏吉，留连/赤口/空亡偏凶。
2. **看三宫关系**：月宫（大环境/起因）、日宫（过程/客体）、时宫（结果/主体）三者的组合与生克。
3. **论五行生克/体用**：看三宫五行之间是"生、克、比和"，以及落宫（体）与时辰（用）的关系。
4. **取数与应期**：需要断时间、数量、方位时，用宫位数、五行方位、季节月份等细化。

> 换句话："先定吉凶→再看来龙去脉→再断细节与时间"。

## 二、三宫（三盘）断法

### 2.1 传统版：月宫、日宫、时宫

| 宫位 | 角色 | 常见断法 |
|---|---|---|
| 月宫 | 大环境、背景、辅助 | 事情的先天条件、大趋势 |
| 日宫 | 客体、对方、过程 | 对方态度、事情发展过程 |
| 时宫 | 主体、自身、结果 | 最终结果、眼前状态 |

民间典型用法："以时辰为主体，以日辰为客体，以月份为辅助来推算。"

### 2.2 道传/民间通行的"天地人"对照表

| 天宫 | 地宫 | 人宫 |
|---|---|---|
| 天时 | 地利 | 人和 |
| 月 | 日 | 时 |
| 父 | 母 | 自己 |
| 起因 | 经过 | 目前 |
| 开端 | 过程 | 结果 |

> 断语示例："做事情时，缺少天时，就算现在不行，以后也行；缺少地利就是政策之类的不行；缺少人和就是自己能力不够。"

### 2.3 断卦提示（道传）
- "夫察五行者，乃无旺相休囚死……宫有宫象，事应已定，吉有吉象，凶有凶象；故生克者，乃三才之应，谓助谓制，**不改其果**。"
- 三宫之间论生克、同、异：**生者为顺助，克者为制转，同者为争复，异者为扶孤**。

## 三、五行生克与体用

### 3.1 五行生克（基础常识）
- 相生：木生火 → 火生土 → 土生金 → 金生水 → 水生木；
- 相克：金克木 → 木克土 → 土克水 → 水克火 → 火克金。
- 记忆：水生木（浇水）、木生火（钻木）、火生土（灰烬）、土生金（矿藏）、金生水（熔金成液）；水灭火、火熔金、刀削木、木疏土、土挡水。

### 3.2 体用关系（道传/江氏共通）

> **以落宫为体，以时辰为用。**体＝卦问之果、事情状况；用＝未来之变、吉凶趋向。

| 关系 | 吉凶 | 含义 |
|---|---|---|
| 用生体 | 大吉 | 外力相助、贵人相助、诸事当成 |
| 体克用 | 小吉 | 主动努力、奋于改变、可成事（"克出"） |
| 体用比和（阴阳为比助） | 吉 | 两相互助、合作相宜 |
| 体生用 | 小凶 | 付出无果、费心费力；问投资可另论（"生出"） |
| 用克体 | 大凶 | 受阻于外、诸事难成；亦有"考察、改造、占有"之意（"克入"） |
| 体用比劫（阴阴/阳阳） | 凶 | 竞力相争、互损互缺、小人阻碍 |

**示例**：
- 落宫速喜（火），时辰亥时（水）→ 水克火，**用克体**，不利；
- 落宫速喜（火），时辰卯时（木）→ 木生火，**用生体**，有利；
- 赤口（阳金）＋酉时（阴金）＝**比助**；赤口（阳金）＋申时（阳金）＝**比劫**。

另注意：三宫之间的生克**不能改变落宫本身的吉凶结果**，只表示"助/制"的过程。

## 四、六亲取用神

### 4.1 六亲定义（以"我"为太极）
- 生我者父母；我生者子孙；克我者官鬼；我克者妻财；同我者兄弟。
- 民间口诀另加"同异我者小人"（用于特殊情形）。
- **六亲类象（江氏）**：自身＝自己；父母＝父母、文化、学习、信息、证件等；兄弟＝兄弟姐妹、同事、同学、竞争、合作；子孙＝儿女、享乐、任性、财源；妻财＝妻子、金钱、资金、财产；官鬼＝丈夫、领导、权力、威望、疾病、灾祸。

### 4.2 江氏用神取法（摘自江阳君教程）

| 用神 | 适用问题 |
|---|---|
| 父母 | 父母、岳父母、祖辈等长辈；衣服、包、鞋、帽子等物品；信息、合同、契约、工作等 |
| 兄弟 | 兄弟姐妹、姑表亲、结拜、同学、同事等同辈关系 |
| 子孙 | 子女、女婿、外甥、侄子等"比我小"者；宠物、家禽；货物、能力、财源；警察、药等"解灾"之物 |
| 妻财 | 男测妻子/女友；测财运及各种财物 |
| 官鬼 | 女测丈夫/男友；疾病、官司、是非、纠纷等灾祸；官员、领导、警察、法官、小人等"管制我"者 |
| 对宫 | 合作、交易、比赛、打官司、借贷、无特殊关系之人等（日时起卦时的日宫／数字起卦的数字宫） |
| 自身 | 占测自己的事，以自身所占之宫为用神 |

> 取用神示例：问父亲事→取"父母宫"为用神（父母宫内所含的六亲、六神、五星等一并取用）；问财运→取"妻财宫"为用神。
> 感情断法的"人宫为卦主、天宫为对方"惯例：若卦主问对方父母，就看"生天宫的"；若对方自己来问父母，则三宫显示的就是父母，不必转六亲。

### 4.3 道传六亲转太极法
- 以落宫为"我"，按生克转出其余六亲：项目生者为获益、克项目者为损耗、生项目者为投资、克项目者为花销……
- 用于"一卦多问"：先断核心问题，再按需转换太极点回答衍生问题。
- 原则："无问者勿动，无需者勿转。"

## 五、江氏小六壬断事步骤（教程28要点）

1. **起课注意事项**：①心意一动、执念最深时起课；②数字起课取第一念之数；③同一件事不反复算；④善用掌上起课（熟练后随时随地可用）。
2. **装卦注意事项**：①先装地支（六神、六亲、五星都由地支来）；②手工装卦要仔细核对；③若解完才发现装错——错卦错断（民间认为也是"天意"）。
3. **取用神**：按上表确定代表所问之事的宫与六亲。
4. **分析用神**：看用神所在的六宫、六亲、六神、五星组合，论生克旺衰、冲合空亡，断吉凶细节与经过结果。
5. **四盘结构**：六宫为地盘／六亲为人盘／六神为神盘／五星为天盘（天盘主天时、大背景）。

## 六、江氏进阶技法（据江阳君教程补充）

### 6.1 活六神法
让六神"动起来"、离开本宫去辅助断卦。现见至少两种版本（属近现代创新技法，非古法）：

**版本A（时辰起青龙法，常见于网络教程）**：
- 六神顺序：青龙、朱雀、勾陈、白虎、玄武、腾蛇；
- 用法：看时辰的排位数，从大安起数到该数（如酉时＝第10位 → 大安数10 → 落"赤口"），即以该宫为**青龙**起点，其余顺排；
- 例（速喜-赤口-小吉-午时问感情）：午时＝第7位 → 从大安数7（回到大安）→ **大安起青龙、留连朱雀、速喜勾陈、赤口白虎、小吉玄武、空亡腾蛇**；于是速喜（天宫）临勾陈、赤口（地宫）临白虎、小吉（人宫）临玄武——原例解为：速喜临勾陈主"勾心、记忆深刻"，赤口临白虎主"大吵后分手"，小吉为桃花临玄武主"暗昧、私下联系（没公开）"。

**版本B（落宫神煞法，另有术者所用）**：以"落宫时辰对应的本宫神煞"为起点，按六宫顺序顺时针排六神；且六神映射存在至少两个版本（①青龙、玄武、朱雀、白虎、六合、勾陈；②青龙、腾蛇、朱雀、白虎、玄武、勾陈）。
> ⚠️ 活六神各家做法不一，有整理者明确表示"并不推荐使用，但也不反对，毕竟是一种创新"——学习时宜知其为后起技法。

### 6.2 地支择法（给三宫配上地支）
- 规则："天宫为阳，地宫为阴，人宫为阳"（大安、速喜、小吉为阳；留连、赤口、空亡为阴）；
  - 阳宫落阳位/阴宫落阴位取**阴支**；阳宫落阴位/阴宫落阳位取**阳支**（"阳落阳取阴支、阳落阴取阳支、阴落阴取阴支、阴落阳取阳支"）。
- 例：大安（阳）-小吉（阳）-空亡（阴），辰时 → 天宫大安取卯（阳见阳取阴）、地宫小吉取子（阳见阴取阳）、人宫空亡取辰（阴见阳取阳）→ 支为"卯子辰"。

### 6.3 地支关系速查（断事吉凶细节）

**地支六合**
| 组合 | 含义（民间释） |
|---|---|
| 子丑 | 逆合、凑合；问事先好后坏，婚姻"凑合过" |
| 寅亥 | 破合；好中有坏 |
| 卯戌 | 淫合、自焚之象；问婚主未婚同居 |
| 辰酉 | 暗合；私下定、不公开 |
| 巳申 | 刑合；在一起就吵、分开又想 |
| 午未 | 明合；公开、实心实意 |

**地支三合**：申子辰合水局、巳酉丑合金局、寅午戌合火局、亥卯未合木局——能量最大的场态，多主和好、合作、团队；半合不如六合旺。

**地支六冲**：子午、卯酉、辰戌、丑未、寅申、巳亥——主离散、冲散、动荡、矛盾。

**地支三刑**：
- 寅巳申（特势之刑）：母子反目、争财动官、手足无情；
- 未丑戌（无恩之刑）：争权、官司、勾心斗角、六亲不和；
- 子卯（无礼之刑）：知恩不报、口舌伤灾、六亲无靠；
- 辰午酉亥（自刑）：不择手段或自我烦恼、身心不健康、斗打是非。

**地支六害**：子未、丑午、寅巳相害——主六亲骨肉不利、脾气、疾病缠身等。
**地支六破**：子酉、寅亥、丑辰、巳申、未戌、卯午——主不成、破裂、从中作梗（常用卯午破）。

### 6.4 墓库应期法
- **辰为水土库、未为木库、丑为金库、戌为火库**；
- 断法："入库取冲就是应期"（例：大安-速喜-留连，未时；木入未库，丑未相冲，丑月为应期）；
- 口诀："**逢刑冲看合，逢合看冲**"。

## 七、道传进阶技法

### 7.1 转太极法（三类）
1. **六亲转太极**：以"我"为中心转出父母、子孙、妻财、官鬼、兄弟，再论彼此生克。
2. **事件关系转太极**：按事情的前后左右关系转（如"项目赚钱几许"→转出"生项目者/项目生者"）。
3. **神煞转太极**：按六神煞的类象转（青龙=事业/学业/喜庆；腾蛇=田宅/阴私/盗匪；朱雀=文书/婚喜/信息；白虎=官非/伤险/警司；六合=酒食/合作/出行；勾陈=牢狱/果报/宅地）。
- 原则："据需而转"，不必每个问题都转。

### 7.2 三宫具象法（简述）
- 将三宫阴阳（大安、速喜、小吉为三阳；留连、赤口、空亡为三阴）按"天居中央得人天地之序""地居中央得天地人之序"等规则排出八卦（乾、坤、震、艮、离、坎、兑、巽），再论天盘八卦与三宫的五行生克（克出、生出、克内、生内、同），转三宫得"具象"——用于深挖细节与来龙去脉。属高级技法，各家版本不一。

### 7.3 分类占提纲（道传卜法卷）
成败、婚情、寻物、罹病、面相、风水、天象、应期等分篇各有细则，例如：
- **寻物**：天=物之态/所居；地=物之变/所趋；人=物之向/所寻；亦可用"转地宫太极"推失物所在。
- **罹病**：天=诱因（六淫、情志等）；地=病之来去轻重；人=何病、结果。
- **面相**：天宫＝上停（额门）、地宫＝中停（准头）、人宫＝下停（地角）。
- **风水**：天宫为向、地宫为座、人宫为入气之流动位；可按时辰五行转动八方。
- **天象**：大安阴晴不定、留连细雨绵绵、速喜响晴霓虹、赤口雷雨冰雹、小吉雨脚漉漉、空亡阴晦难明。

## 八、应期断法（断时间）

### 8.1 六神季节/月份（道传）
| 宫位 | 季节 | 地支月份 |
|---|---|---|
| 大安 | 春 | 寅、卯、辰月 |
| 留连 | 春夏/四季 | 辰、巳月（或辰戌丑未月） |
| 速喜 | 夏 | 巳、午、未月 |
| 赤口 | 秋 | 申、酉、戌月 |
| 小吉 | 冬 | 亥、子、丑月 |
| 空亡 | 冬春 | 丑、寅月（或辰戌月） |

### 8.2 宫位数（谋事数）
- 传统口诀直接给出"谋事主一五七/二八十/三六九/四七十"——断天数、件数、人数、排名时使用；
- 断近期以"日/时"为单位，断远期以"月/季/年"为单位；
- 男女、阴阳、事件性质不同，取数会有调整（如道传取数：大安男孩取4数、女孩取5数）。

### 8.3 体用远近、三宫生克与墓库
- 以体用生克定"快慢远近"；三宫五行生克缓急（生者缓、克者急）辅助判断"事何时显、何时终"；
- **墓库法**：入库取冲为应期（见6.4）；
- 具体应期"无定法"：取年、取季、取月、取日、取时，视所问之事而定。

### 8.4 实用提醒
- 问"何时"要结合问题性质：问考试、面试多取日/时；问婚事、买房多取月/季；问人生大势多取年。
- 务实的做法：给**时间范围**而非精确日期（如"三到七天内""这个季度内"），并说明这是推测。

## 九、数字取数法（断数量、分数、排名）

- **明数**：宫位排位数（大安1、留连2、速喜3、赤口4、小吉5、空亡6）＋先天八卦数（震巽4/5、艮坤7/8、乾兑1/2、坎6、离3）＋河图数（如空亡5/10）。
- **隐藏数**：一轮回后继续叠加——大安藏7、留连藏8、速喜藏9、赤口藏10、小吉藏11、空亡藏12；再往上即1、7、13……2、8、14……以此类推。
- **取法示例**：考试名次落大安→取1（第一名）；若前面宫位不佳、需修正，则男孩取4、女孩取5；分数/日期同理（"男取阳数、女取阴数"）。
- **原则**："先以卦的吉凶论事，再看数字"；取数要当机立断、脱口而出，犹豫反而不准。
- **实战示例**：某网友心动起卦 447 申时（赤口-大安-大安），两金克人宫大安，断"必跳"；大安取数1/4/5，对方是女孩取5，5分钟后果然跳了（来源：网络案例，仅作方法演示）。

## 十、综合断卦示例（学习用）

### 示例A：传统三宫（三月初五辰时）→ 小吉
- 三月速喜、初五大安、辰时小吉。
- 断"去西南办事"：小吉主和合、路上好商量，行人立便至、交易甚强——宜行，多有贵人相助；结合数字"一五七"可断事情大约三、五、七日（或涉及一、五、七个相关人物/事项）。

### 示例B：江氏"装六亲"（教程11）
- 张三于农历正月初六戌时问"能不能娶上村长闺女"。
- 地支：赤口戌、小吉子、空亡寅、大安辰、留连午、速喜申；身宫赤口（戌土）：
  - 子水（小吉）被戌土克 → 妻财；
  - 寅木（空亡）克戌土 → 官鬼；
  - 辰土（大安）同戌土 → 兄弟；
  - 午火（留连）生戌土 → 父母；
  - 申金（速喜）被戌土生 → 子孙。
- 用法：妻财=对象、官鬼=阻力/岳父家、兄弟=竞争者……一目了然。

### 示例C：感情（网络案例）
- 子时一女生测感情：速喜-速喜-留连-子时。
  - 天宫速喜为火，"克天宫的年份为在一起的时间"：当年壬寅年，水克火 → 今年在一起；
  - 留连为停滞、担忧；天地都生人宫 → 女方占优势，主"担忧"而非"停滞"——反馈：怕异国恋出矛盾想分手，想看注意什么；
  - 对方速喜（地宫）之火热而不持久 → 谨防对方"三分钟热度"。

### 示例D：寻物（网络案例）
- 速喜-留连-空亡（无其他信息时）：
