# 小六壬 · 起卦方法（时间 · 报数 · 外应）

> 起课（起卦）是一切断法的前提。本文汇总：掌诀定位、时辰换算、传统"月日时"起课、报数起课、外应/心动起课，以及**江氏小六壬的三种主流起课法（日时/时刻/数字）与其装卦四步**。
> 说明：不同流派起课细节不同（传统用"月日时"，江氏用"日时/时刻/数字"），本文并列呈现，供对照学习。

---

## 一、掌诀定位（六宫在左手的位置）

以左手为例（各家表述一致）：

| 位置 | 宫位 |
|---|---|
| 食指**根部**（下节） | **大安** |
| 食指**指尖**（上节） | **留连** |
| 中指**指尖**（上节） | **速喜** |
| 无名指**指尖**（上节） | **赤口** |
| 无名指**根部**（下节） | **小吉** |
| 中指**根部**（下节） | **空亡** |

**掐算顺序永远固定不变**：

> ①大安 → ②留连 → ③速喜 → ④赤口 → ⑤小吉 → ⑥空亡 →（回到大安）

用左拇指依次掐点即可；一宫一数，循环往复。

## 三、传统时间起课法（月上起日、日上起时）

**口诀：大安起正月，月上起日，日上起时。**

### 步骤
1. **起月**：无论哪个月，都从"大安"起正月，顺数至所求月份，落在某宫。
   - 正月大安、二月留连、三月速喜、四月赤口、五月小吉、六月空亡、七月又回大安……（月份减1后除以6取余：余0=大安、1=留连、2=速喜、3=赤口、4=小吉、5=空亡）。
2. **起日**：从"月落宫"起初一，顺数至所求日辰，落在某宫。
3. **起时**：从"日落宫"起子时，顺数至所求时辰，落在某宫——**最终落宫即本课答案**。

### 例1（古书原例，三月初五辰时）
- 三月落**速喜**；
- 速喜起初一：初一速喜、初二赤口、初三小吉、初四空亡、初五**大安**；
- 大安起子时：子大安、丑留连、寅速喜、卯赤口、辰**小吉**。
- 结论：落宫**小吉**（《玉匣记》原文即以此为例："数至辰时即是小吉"）。

### 例2（十一月例）
- 十一月：大安(1)→留连(2)→速喜(3)→赤口(4)→小吉(5)→空亡(6)→大安(7)→留连(8)→速喜(9)→赤口(10)→**小吉(11)**；
- 若为十一月初十：小吉起初一……初十落**留连**；
- 再从留连起子时，数到所求时辰。

### 三宫的读法
最终得到三个宫位（月宫、日宫、时宫）。常见定位：
- **月宫**：大环境、背景、辅助信息；
- **日宫**：事情的过程、对方/客体；
- **时宫（落宫）**：眼前结果、主体、自身。
> 道家/道传体系则把三宫改称"天、地、人"：天=起因、地=经过、人=结果（详见06文件）。

## 四、报数起卦法

### 4.1 通用"报三数"法（现代最常见）
1. 心中默念所问之事，随意想出**三个数字**（一说 1—1000 以内皆可）。
2. 从**大安**起，数第一个数字，落在某宫；
3. 以该宫为起点，数第二个数字；
4. 以第二个落点为起点，数第三个数字——**最终落宫为答案**。
5. 数字大于6时，按循环进位（等价于**除以6取余数**，整除时取6）。
   - 例：数字 11 → 11÷6 余5 → 相当于数到"小吉"；数字6或12 → 空亡。

### 4.2 民间版细则（转引自网络整理）
- 报 1—9 之间的三个数字；若报"0"则按 10 取落宫；
- 起法："以落宫为第一个数往后顺时针数起"（即下一数字从上一落宫起步）。

### 4.3 三宫对应
- 第一个数字/宫 → 月宫（起因/大环境/天）；
- 第二个数字/宫 → 日宫（经过/客体/地）；
- 第三个数字/宫 → 时宫（结果/主体/人）。

### 4.4 实例（网络常见例）
- 数字 3、6、3：大安起数3→速喜；速喜起数6→速喜（循环一圈）；速喜起数3→赤口。
- 数字 1、6、8：大安(1)、空亡(6)、大安(8)。

## 五、江氏小六壬起课三法（重点补充）

江氏（江春义/江阳君体系）不使用"月日时"，而用以下三种最实用的起课法：

### 5.1 日时起课法（最基础）
- 规则：**从大安宫上起日，日上起时辰**（日期用阴历）。
- 示例：3月初3早晨8点20分求测：
  - 大安起日，数3下（初1大安、初2留连、初3速喜）→ 落**速喜**；
  - 速喜宫起子时，顺数到辰时（8:20为辰时）：子速喜、丑赤口、寅小吉、卯空亡、辰**大安**。
  - 结论：日宫速喜、时宫大安。
- 缺陷：一个时辰两小时内问什么都同卦。

### 5.2 时刻起课法（解决"同一时辰同卦"）
- 规则：**从大安起时辰；再从时辰落宫起"刻"**。
- 刻的算法：每时辰120分钟，**10分钟为一刻，共12刻**，依次为子刻、丑刻、寅刻……亥刻（第1个10分钟=子刻，第2个=丑刻，依此类推）。
- 示例：上午11点25分求测：
  - 大安起子，数到午时 → 落**大安**；
  - 11:25是午时的第3个10分钟＝**寅刻**；大安起子，数到寅 → 落**速喜**。

### 5.3 数字起课法（江阳君最推荐）
- 规则：让求测人**心无杂念、只报一个数字**（位数不限，取浮现的第一个）；用该数**除以6取余数**，从大安起数余数；再**从该宫起时辰**。
- 示例：15:58（申时）报数 9：9÷6余3 → 大安起数3落**速喜**；速喜起子数到申 → 落**小吉**。
- 优点：同一时刻多人求测也不会重卦；数字由求测人自报，信息对应性强。
- 其他（"法无定法"）：骰子起课、翻书页数、车牌号等皆可，关键是**心意一动时的第一个数字**为准。

## 六、江氏装卦四步（起课之后）

卦起好后要"装卦"（排卦），顺序为：**装地支 → 装六亲 → 装六神 → 装五星**；六宫位置固定，其余均按规则排列。

### 6.1 装地支（先装地支，其余都由它派生）
- 规则：**以时辰地支落宫为准，然后顺时针隔位排地支（跳过中间地支）**。
- 示例（江氏经典卦例：正月初六戌时）：
  - 日时起课：大安起日数到初六→空亡；空亡起子数到戌→赤口；**赤口配地支戌**；
  - 隔位排：赤口戌 →（跳过亥）小吉子 →（跳过丑）空亡寅 →（跳过卯）大安辰 →（跳过巳）留连午 →（跳过未）速喜申。
  - 全盘地支：赤口戌、小吉子、空亡寅、大安辰、留连午、速喜申。
- 数字起课同理：先数数字落宫 → 落宫起时辰 → 定地支 → 隔位排满。

### 6.2 装六亲
- **以时辰落宫为身宫**（代表卦主自己），以"我"（身宫地支五行）与其余各宫地支五行论生克：
  - 生我者父母，克我者官鬼，我生者子孙，我克者妻财，同我者兄弟；
  - 若"我"为子午卯酉寅申巳亥（无同类土），则从身宫顺时针找**第一个属土的地支**为兄弟。（示例见06文件）

### 6.3 装六神
- 六神顺序：**青龙、朱雀、勾陈、白虎、玄武、腾蛇**（口诀："龙头蛇尾"）。
- 排法（以"身宫地支"定起点）：子午大安起青龙、丑未留连起青龙、寅申速喜起青龙、卯酉赤口起青龙、**辰戌小吉起青龙**、巳亥空亡起青龙，然后顺时针排。
- 示例（身宫戌）：小吉青龙 → 空亡朱雀 → 大安勾陈 → 留连白虎 → 速喜玄武 → 赤口腾蛇。

### 6.4 装五星（辅助断课，可以不起）
- 五星实为"五行＋空"共六位：**木、火、土、金、水、空**。
- 规则：从"日落宫"（时刻起卦＝时宫；数字起卦＝数字落宫）起**木星**，然后顺时针按 **木→火→土→金→水→空** 排满六宫（相邻相生）。
- 示例（日宫空亡）：空亡木星 → 大安火星 → 留连土星 → 速喜金星 → 赤口水星 → 小吉天空。

### 6.5 检查与"错卦错断"
- 手工装卦务必核对；若解完卦才发现装错——**错卦错断**，不必重来（民间认为这也是"天意"）。

## 七、外应起卦与心动起卦

- **心动即占**：真正想问的念头最强、心血来潮的那一刻起课最准（江春义：心意一动的第一时间；执念最深时）。
- **外应起卦**：起卦时把眼前"不寻常的现象"纳入参考，如突然听到的声音、看到的人/动物/颜色/物品、打翻东西、落叶飞花等（与梅花易数相通的思路）。
- **遇事即卦**：事情突然发生、有人开口找你问事的那一刻，即可用当时的时间起课。

## 八、道家/道传小六壬起课（对照）

- 以"天时之法"自居：取**月、日、时**三数起三宫（天盘、地盘、人盘）。
- 落宫为**体**，时辰为**用**；先观三宫六神成象，再论体用与五行生克（见06文件）。
- 亦可"以问时、以随心、以外应"起卦——"风鸟声物者皆可起卦"。

## 九、日本六曜的日课推算（对照参考）

旧历"月份＋日期"之和：
- 和除以6：整除→大安；余1→赤口；余2→先胜；余3→友引；余4→先负；余5→佛灭。
- 例：旧历6月1日 = 7 → 余1 → 赤口；旧历5月1日 = 6 → 整除 → 大安。

## 十、起课心法（各家的共同提醒）

1. **有疑才占**：无事不占、不疑不占、不诚不占、不义不占（"三不占/四不占"详见07文件）。
2. **当场起课**：念头最强时马上起；报数取**脑子里浮现的第一个数字**，不要挑来挑去。
3. **一事一课**：同一件事不要反复起课；结果不好也不要换个时辰重占。
4. **安静专注**：起课前可深呼吸、心念专一；避免嬉笑打闹中起课。
5. **记录保留**：写下问题、时间、三个落宫与当时的"外应"，便于复盘学习。
