# 凡例（写在前面）

> 本书是传统文献与当代公开材料的来源审阅和民俗研究汇编。2026-10-13 起，旧稿中许可未核的技术细节、歌诀、案例摘录和结构化表格不再作为公开内容。

## 一、本书的用途

1. 区分古籍记载、当代作者自述、研究者解释与第三方转述。
2. 记录材料的来源、版本、可核位置、发布依据和未决问题。
3. 展示如何纠正过度推断、维护来源清单并进行结构与内容双审计。
4. 为后续找到原件或许可后开展的专题研究保留可追踪线索。

本书不提供完整占卜操作教程，也不证明任何预测方法的效果。公开页面中的名称或作者说法，只能按页面事实和自述归属记录。

## 二、来源与发布范围

公开访问、免费阅读、限时免费领取、软件免费使用和允许某篇文章转载，是不同的事实。每一项按其作品、页面、图片、附件、程序和数据对象分别核验。单篇转载说明不推定适用于系列文章、整本电子书或派生数据库。

引用时应标明作者、作品名和原始位置；只取研究目的必要的部分。若拟公开整篇、整表、案例合集、扫描件、程序或数据库，应先确认覆盖该发布方式的权利依据。

## 三、内容阅读提示

| 材料类型 | 本书处理 |
|---|---|
| 古籍、馆藏和历史资料 | 记录具体版本和原文位置；异文未核时保持待核 |
| 当代流派文章 | 标明作者及其自述性质，不当作历史证明 |
| 第三方扫描/笔记/目录 | 作为检索线索，不推定权利、版本或内容准确 |
| 民俗信仰和术数说法 | 仅作文化研究对象，不作事实、医疗或现实决策依据 |
| 项目分析 | 明确作为研究者判断，列出证据和局限 |

## 四、维护与复核

每轮内容变化依次完成：更新来源状态表；回查受影响原文；修订研究文档和书稿；执行结构审计与内容审计；人工复核命中项；第二人独立检查引用、许可、目录和派生文件；重建合订本/PDF；记录版本和远端同步状态。
