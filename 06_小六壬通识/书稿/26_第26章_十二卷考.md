# 第26章　"十二卷"考

> **本章导读**："道家小六壬一共十二卷"——这句话在市场上流传极广。但十二卷到底是什么、有没有实物、值不值得追？这一章把关于十二卷的所有证据摆上桌，给出一个尽量诚实的判断。

## 26.1 两份独立转述

**邵系自述**：

> "小六壬也是最繁杂之学，它十二卷内容涉及**卜法、命法、地法、择法、香法、阴法（癔法）、解法、禁法、壬法、修法、穿法、遁法（隐法）**，其中包含有符咒与神通之术……"

**江春义（竞争流派的旁述，2023）**：

> "道家小六壬……一共有 **12 卷**，分别为卜法、命法、地法、择法、香法、阴法（癔法）、解法、禁法、壬法、修法、穿法、遁法（隐法），也就是网上流传的道家小六壬 12 卷。"

**结论①**："12 卷"的说法至少被两个不相关来源复述，流传甚广；但**两者均为转述，均未出示实物文献**。

## 26.2 各卷内容推测

| 卷名 | 推测内容 | 依据 |
|---|---|---|
| 卜法 | 占断人事（三盘、六神、类象、分类占） | 有公开的《卜法浅要通则》 |
| 命法 | 以盘论命 | 邵氏称六道内容"主要在命法卷体现" |
| 地法 | 风水／地理 | 名称＋卜法卷含风水篇 |
| 择法 | 择日选时 | 与六曜择日血统呼应 |
| 香法 | 香占（分香） | 邵氏自述擅长"分香法" |
| 阴法（癔法） | 阴事、癔病类 | 名称＋提及 |
| 解法 | 化解禳解 | 名称 |
| 禁法 | 禁忌、禁咒 | 名称 |
| 壬法 | 六壬相关专法（不明） | 名称，无内容 |
| 修法 | 修持（"本气法"） | 邵氏称"很重要" |
| 穿法 | 用小六壬穿其它术数 | 原文提及"穿大六壬、奇门、太乙、六爻、梅易" |
| 遁法（隐法） | 遁匿类法门 | 名称 |

## 26.3 传承叙述与"当代重建"判断

传承时间线（1999 收集→七尘子受教→2007 神咒与拜师→2008—2010 整理写作→2011 公开）详见第 19 章。从**考证角度**看要点只有一句：

> 邵一尘是**当代人**，其体系是"师父口传＋个人整理＋咒语传承"的**当代重建**，并非有明确考古／文献链条的古籍。自称"道家传承十二卷"，本质是**当代师承叙述**。

## 26.4 市场流传与独立验证

**（一）公开可见的只有"卜法卷"部分**：《卜法浅要通则》全文可查（本书第 12—13 章的技术内容主要来源于它）；其余各卷为**名称级信息**。

**（二）"六卷"与"十二卷"的关系**——三源重合：

| 来源 | 六卷名单 |
|---|---|
| 江春义（《浅谈道家马前小六壬》） | 命法、卜法、癔法、解法、择法、香法 |
| 第三方转载（free68.net） | 香法、卜法、命法、解法、癔法、择法 |
| 市面流出卷本 PDF | 卜法、命法、择法、解法、香法、癔法 |

→ 可作**观察**（不裁定）："六卷"可能是该系**原始的流传口径**；"十二卷"＝六卷＋（地法／禁法／壬法／修法／穿法／遁法）的扩充叙述。

**（三）真伪的警告**：

- 邵氏自述：市面流传的"六卷本"经与师传比对"亦非真本，**或有做过人为的修改，故意改错**"；
- 市面所有卷本 PDF 均为**付费资源站的目录级证据**，本资料包未下载、未核验；
- **反证**：江阳君 2024 年辟谣——有人称"江氏小六壬有 14 本秘籍"，他回应"作为传人，我都不知道吾家还有这么多秘籍"——说明市场上存在普遍的**"卷数膨胀"营销**（12 卷、14 本、秘籍大全……）。

## 26.5 审计结论（五条）

1. **名称清单可信度中等**：两方独立复述一致，且与公开的卜法卷内容逻辑自洽；但均属口头转述，无实物；
2. **完整内容不可采信为"已失传古籍"**：属当代重建的师承叙述；
3. **与《一掌经》的关联**：六道十二宫明显借自托名一行的《一掌经》——说明该体系是**多来源拼合**（六曜＋六神＋一掌经＋符咒等），并非一套独立传承的"古本十二卷"（第 27 章）；
4. **实用建议**：学"道家小六壬"直接看公开的卜法部分即可；对命法、解法、禁法、修法、穿法、遁法中含符咒／神通的卷本**保持理性距离**，不建议投入金钱购买所谓"真本"；
5. **理解方式**：把"十二卷"理解为**体系框架的宣传性表述**，比当作"失传秘笈"更稳妥。

## 本章要点

- "十二卷"：两方转述一致、流传广、**无实物**；完整内容从未公开。
- "六卷 vs 十二卷"三源重合——"六卷或为原始口径"（观察，不裁定，分歧 9/10）。
- 体系性质：**当代重建的多来源拼合**；卜法部分可学，其余按门禁名称级对待。
- 警惕"卷数膨胀"营销（12 卷、14 本之类）。
