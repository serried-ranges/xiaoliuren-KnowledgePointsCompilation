# 第28章　道家马前与命法三轴

> **本章导读**：第 21 章介绍过江春义所述的"道家马前小六壬"六卷。这一章深入它的**命法卷**：三件民间"以六宫论命"的诀文材料——三寸金、小透玄、马前一掌经——与邵系命法、《一掌经》放在一起对照，看"命法"在民间到底长什么样。

## 28.1 三道命法诀文从哪里来

2024 年，江春义连发《浅谈道家马前小六壬》三篇，公开了其所述"道家马前"命法卷的部分原文：**三寸金、小透玄**（另有卜法卷《马前六壬掌中诀》、癔法卷《马前外病总诀》，癔法部分按门禁处理，见第 21 章）。2024 年 12 月，他又发表《马前一掌经论命》（一）（二），给出两个实例。

这是"命法／占命"在公开层面**首批可核的原文与实例**——尽管来源单一（江春义转录），且其所称"与道家六卷占命基本相同"的所有权说法无法独立验证。

## 28.2 命法三轴

### 28.2.1 三寸金：月轴（生月→宫）

**结构**：把**出生月份**直接对应六宫（正好就是小六壬"大安起正月"的起月规则），每月一句歌诀断命：

| 生月 | 落宫 | 歌诀首句（样貌） |
|---|---|---|
| 正月 | 大安 | 大安性情直…… |
| 二月 | 留恋 | 留恋运不稳…… |
| 三月 | 速喜 | 速喜闹东堂…… |
| 四月 | 赤口 | 赤口有桃情…… |
| 五月 | 小吉 | 小吉力多能…… |
| 六月 | 空亡 | 空亡心聪颖…… |
| 七月 | 大安 | 大安同父换…… |
| 八月 | 留恋 | 留恋共潮生…… |
| 九月 | 速喜 | 速喜官不和…… |
| 十月 | 赤口 | 赤口卧寒松…… |
| 十一月 | 小吉 | 小吉性情倔…… |
| 十二月 | 空亡 | 空亡心刚强…… |

**关键发现**：三寸金＝**把"月日时起课"的第一步（月宫）单独抽出来当命盘用**。歌诀主题覆盖性格、官运、财运、婚姻、六亲与灾咎——属典型的**民间命课歌**。（余下各句含刑克类旧说，本书不逐句转录。）

### 28.2.2 小透玄：日轴（日坐宫）

**结构**：以"**日坐某宫**"为命局主语，共 6 组 × 3 句，旁参月、时宫：

| 主句 | 主题（摘要） |
|---|---|
| 日坐大安 | 心慈祥；早年坎坷、晚景吉昌 |
| 日坐留恋 | 走江川、心直口快；逢大安、小吉有吉象 |
| 日坐速喜 | 巧舌、好礼；感情婚姻多波折 |
| 日坐白虎（赤口） | 性情怪、口舌快；月日重照则多曲折 |
| 日坐小吉 | 人多情、桃花泛水；受克则福不清 |
| 日坐空亡 | 财禄重、女命刚强；时临吉宫转好 |

**术语对照**——它和小六壬共用一个轮盘，却借用了八字命理的词汇层：

| 小透玄用语 | 含义 | 邵系对应概念 | 一掌经对应 |
|---|---|---|---|
| 日坐 X | 以日宫落宫为命局主语 | 体（落宫为体） | "时辰落在 X 星" |
| 临时 X | 时宫的作用 | 用（时辰为用） | — |
| 重照／重连 | 月、日、时同宫重见 | 比和／伏吟之象 | 星重（犯重） |
| 受克／逢克 | 被它宫五行所制 | 制转（克） | "犯重者……" |
| 禄马学堂 | 命理吉象（禄、驿马、学堂） | — | —（民间命理借词） |

### 28.2.3 马前一掌经：全盘轴（出生月日时）

江春义自述：

> "在民间确实流传一种**马前一掌经占命方法**……**与道家六卷占命基本相同**……其实马前课占命**非常简单，只看六亲和六宫**。"
> "起法是根据当时人**出生的生日时辰起盘**……还要看**六亲所临的宫位**来看父母、兄弟姐妹、子女、事业、财运等情况。"

**两个实例（摘要）**：

- **例 1**：属猴者，九月十二寅时生——"子孙落在留恋"→断其贪玩、慢慢腾腾、有贵人朋友帮衬但"不争气"、无事业心、不利官运，但为财奔波（子孙落留连多主操劳）；
- **例 2**：男，1962 年十月十八子时生（属虎）——性格外向、大方、单纯、易轻信、犯桃花；"父母落留恋"→人老实但爱叨叨、借不到父母光；妻子落空亡→人品好、心宽。

**意义**：这是"命法卷"在民间实际样貌的第一批可核原文——**起盘＝出生月日时（与卜法同构），断法＝六亲落宫＋宫位组合**，即把占卜盘直接当命盘用。

## 28.4 学理观察

1. **"以六宫断命"的三条轴**：月轴（三寸金）、日轴（小透玄）、全盘轴（马前一掌经）——民间把占卜盘"命盘化"的三条路径，全部可溯源到**月日时轮盘**；
2. **与六曜算法同构**：日本六曜把"月＋日"之和压进六名循环；三寸金把"生月"直接对应六宫——同为"历注式六名循环"的思维遗存；
3. **术语层累**：书面体系用"体用／生克"，民间口诀用"坐／临／照／克"——同一逻辑的两套话语；
4. **文献史价值**：三件材料是研究"命法卷"的首批可核原文，填补了此前"名称级信息"的空白；
5. **待办**：一刀斩、百句金口令、铺地金、马前关煞诀等其余命法诀文，公开层面**仍未获得**（第 30 章追踪）。

- 命法三轴：三寸金（月轴）、小透玄（日轴）、马前一掌经（全盘轴）——民间"以六宫论命"的三条路径，均源于月日时轮盘。
