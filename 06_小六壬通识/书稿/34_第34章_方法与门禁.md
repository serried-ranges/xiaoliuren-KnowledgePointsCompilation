# 第34章　方法与门禁

> **本章导读**：这本书是怎么写的？哪些内容被收、哪些被降权、哪些被拒收？冲突为什么"不裁定"？这一章公开本书（及其研究层）的全部内容规则——读者可以用它来检验全书，也可以用它去衡量市面上任何一份小六壬资料。

## 34.1 立场声明

本书是**民俗文化研究读物**。"收录≠采信"：迷信内容作为**研究对象**保留其文本样貌，但其"效力宣称"一律降权为零（不成立、不推荐、不指导实操）。

## 34.2 采信分级（A / B / C / D）

| 级别 | 定义 | 处理动作 | 典型示例 |
|---|---|---|---|
| **A 高** | 古籍原文、实物影像、学术机构/辞书、可核事实 | 正常引用 | 《玉匣记》《居家必用》影印、《协纪辨方书》、《头书长历》、辞书 |
| **B 中** | 当代传承自述、公开教程与案例（"某系如此说"层面的可核事实） | 可引用为"该体系内容"，**不作效力断言** | 邵系七篇、《卜法浅要通则》、江氏教程、案例集 |
| **C 低（仅存档）** | 民俗信仰、神通符咒、法术宣称、命理恐吓断辞 | **永不采信**；显著标注；仅作民俗文本存在记录；不用于实操/传播 | 外病总诀、收魂、符咒叙述、"克夫克妻少亡"类断辞、神咒修持 |
| **D 忽略** | 营销话术、诈骗风险内容、低质内容农场、无法溯源 | **不收录**（仅在审计记录中注明"曾见并忽略"） | "百分百准确""改命转运收费""大仙看病"广告 |

## 34.3 政治原则门禁（一票否决·最高优先级）

先于 A/B/C/D 分级：**任何内容一旦触碰政治原则，无论质量高低，一律拒收/剔除。**

- 坚持**一个中国原则**；港澳按中国香港、中国澳门表述；
- 不出现任何暗示分裂国家属性的表述；涉台机构名用规范称谓（如台北故宫博物院）；
- 不涉及政治与国运占测。

## 34.4 三条红线（任何级别均适用）

1. **健康**：不提供任何替代就医的"治病/疗病"实操指引；相关内容只作历史文本描述；
2. **法律/财务**：不推荐以占卜做决策；相关纠纷只作民俗现象记录；
3. **恐吓**：旧时代断辞中的"牢狱/折寿/克亲"等话语，引用时必加"旧时代话语·民俗记录"标示。

## 34.5 门禁检查清单（新内容准入必过）

1. 政治合规（一票否决）；
2. 来源可溯（URL/出处/日期齐全）；
3. 类型判定（原文/转述/营销/未知）；
4. 敏感扫描（六类词：神通符咒/仙鬼巫/命理恐吓/改运化解/信仰供养/疾病干预）；
5. 命中 C 级 → 加警示＋登记＋客观转述、不背书；
6. 命中 D 级 → 拒绝收录；
7. 涉健康/法律/财务 → 强制加"不替代专业意见"；
8. **信息冲突 → 并列记录、不裁定**；
9. 通过 → 入包，并接受每轮双审计。

## 34.7 冲突处理五原则

本书正文出现 ⚠️ 分歧框的地方，以及附录 F 的 22 条登记，均按以下规则处理：

1. **并列记录，不裁定**；
2. **示出处**（标明来源层级）；
3. **固定一套**（学习者实践时不中途换规则）；
4. **不做跨系嫁接**（混搭须注明自创）；
5. **随证据更新**（"待核"事项出现实物证据即修订）。

## 34.8 双审计机制

- **结构审计**：文件清单、索引完整性、交叉引用、版本戳、来源编号、**政治合规扫描**；
- **内容审计**：六类敏感词全量扫描，输出分布报告；
- **流程**：更新内容 → 跑双审计 → 修问题 → 记录（本书的每轮结果见书稿审计记录）。

## 34.9 本章要点

- A/B/C/D 分级＋政治一票否决＋三条红线，是本书全部内容的准入规则；
- C 级内容"只写它说过什么，不写怎么做"；D 级不收录；
- 冲突五原则：并列、示源、固定、不嫁接、随证更新；
- 读者可在附录 F 与书稿审计记录中检验本书的自我执行。
