# 第31章　研究与阅读路径

> 旧版学习路径包含现代来源的操作规则、练习题材和案例推荐。相关电子书、扫描件和传播笔记的公开许可未闭环，本章改为可复核的资料研究路径，不提供未核授权材料的技法说明。

## 31.1 阅读顺序

1. 从《附录 E 来源清单》和《05_书籍整理/公开材料状态表.md》了解材料类型、访问入口和发布状态。
2. 阅读古籍研究时，先确认具体版次、馆藏页、卷页和异文，再比较现代转述。
3. 阅读当代流派资料时，区分作者自述、研究文章、第三方转载和项目推断。
4. 阅读案例时，记录它是发布者自选材料还是独立研究样本，不把个案反馈当统计证据。
5. 对健康、法律、财务或其他重大事务，使用相应专业服务，不依据民俗文本作现实决策。

## 31.2 研究记录模板

每条待核主张建议记录：

| 字段 | 内容 |
|---|---|
| 主张 | 可被核对的一句话，不混入解释 |
| 来源 | 编号、作者、题名、URL、发布日期 |
| 原文位置 | 页码、段落、图号或馆藏标识 |
| 材料类型 | 古籍原文、作者自述、研究文章、第三方传播、项目推断 |
| 核验状态 | 已核、部分核验、待核、撤回 |
| 发布范围 | 可链接、可短引、可转载、可改编、可镜像或未授权；逐项记录 |
| 复核 | 第二审阅者、日期、结论和未决问题 |

## 31.3 版本维护

每次更新先修订来源状态表，再修订研究文档与书稿；随后生成合订本，运行结构和内容双审计并由人工复核命中项。版本记录应说明新增证据、撤回内容、审核日期与生成文件，避免只记录文档数量。
