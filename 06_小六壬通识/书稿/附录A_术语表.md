# 附录A　资料审阅术语表

| 术语 | 本书用法 |
|---|---|
| 原始来源 | 可定位到作者、出版社、馆藏机构或原发布平台的作品页面或实物版本 |
| 传播件 | 经第三方转存、扫描、摘录或排版后流通的文件；不自动证明版本准确或传播者有再授权权 |
| 作者自述 | 作者对师承、年代、体系、经验或方法所作的陈述；须标明归属，不等同于独立史实 |
| 二手研究 | 研究者基于可见材料所作的整理或分析；需说明使用了哪些来源和证据范围 |
| 转载声明 | 某作品页面对再发布所写的条件；应记录适用对象、页面、作者、作品名和使用方式 |
| 许可范围 | 许可允许使用的具体作品、对象、媒介、修改、汇编、传播方式和期限 |
| 公有领域标记 | 文件平台对某文件所显示的权利状态标记；说明平台记录，不必然代表来源机构单独许可 |
| 事实性摘要 | 为说明研究问题所作的简短概述；应与原文区分，保留必要来源定位，不代替原作 |
| 撤回 | 将无法确认来源、版本或发布依据的内容从当前公开版本移除，并记录原因 |
| 待核 | 现有证据不足以支持确定结论或发布范围的状态；不得通过推测补齐 |
| 结构审计 | 检查文件目录、编号、内部引用、版本和生成文件是否一致 |
| 内容审计 | 扫描敏感词并人工判断其语境、来源、断言强度和现实风险 |
| 双人复核 | 第二位审阅者独立回到原始材料核验引用、许可和文稿同步；不是只看第一审阅者的摘要 |
