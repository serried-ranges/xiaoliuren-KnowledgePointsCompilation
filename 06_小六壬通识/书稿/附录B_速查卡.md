# 附录 B　阅读与核源速查卡

> 本附录帮助读者核对来源，不提供未经许可的逐宫表、数字、口诀或操作公式。

## 速查卡 1：遇到一条规则时

1. 记录作者、标题、发布时间和原始网址。
2. 确认它属于古籍、作者公开文章、官方工具、转载整理本还是来源不明材料。
3. 阅读页面的转载/许可说明，并区分“免费使用”“限时免费领取”“转载需注明”和“开放许可”。
4. 摘要时注明出处，不把作者自述写成独立史实。
5. 找不到来源或发布许可时，只留来源卡，不发布全文、逐项表格、歌诀或案例。

## 速查卡 3：内容双审计

- **结构审计**：核对目录、文件清单、编号、交叉链接、来源编号、版本日期和生成文件。
- **内容审计**：核对主张与来源、原文/转述/推断标签、授权范围、敏感内容提示和已撤回结论残留。
- **复核结果**：记录扫描日期、报告文件、问题、修复和复跑结果。
