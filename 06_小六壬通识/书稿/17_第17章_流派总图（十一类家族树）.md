# 第17章　流派名称与证据边界

> 旧稿曾把多种流派名称排列成家族树，并据第三方摘要归纳起课、用神和技法差别。具体技术特征、派生关系和传承时间线未经独立材料充分验证，且部分细节依赖许可未核的传播件。本章只保留名称级文献导航。

| 名称线索 | 当前可做的记录 | 尚不能据此判断 |
|---|---|---|
| 民间马前课 | 古籍与民间文献中出现相关用语 | 具体起源、单一源头或连续传承 |
| 李淳风六壬时课 | 可按《玉匣记》具体版本核验题名和原文 | 托名人物确为作者、所有版本一致 |
| 道传/道家小六壬 | 可记录当代公开页面、作者自述和二手研究 | 古代法脉、卷本完整性或各传播版本同源 |
| 江氏小六壬 | 可记录江春义、江阳君及官方网页和公告 | 未逐篇核验教程内容、全系许可或其他材料权属 |
| 乐命堂、中六壬、马前双留恋等 | 可列为公开材料中的检索名称 | 具体规则、数量宣称、技术关系或传播年代 |
| 日本六曜 | 可用历史文献研究其历注记录 | 与小六壬之间的具体传播路径，除非原文证据闭合 |
| 第三方派生及市场名称 | 仅保留可核网页题名和发布者 | “谁从谁来”、抄袭/派生判断及技术同异 |

## 阅读纪律

1. 将名称记录、作者自述和历史结论分开。
2. 传承与年代判断要有一手原始文献或独立交叉证据。
3. 不能由相似名称或第三方目录推断内容相同。
4. 技术细节需另行核验来源与许可；来源不明时不作为体系特征发布。
