# 第11章　六宫名称与版本阅读

> 六宫名称在不同通书、当代教程与流派材料中会被赋予不同含义。本章只给阅读方法和名称级提示，不复录来源许可未核的逐宫表、数字、口诀或案例。

## 11.1 六个宫名

| 宫名 | 字面提示（非完整断语） |
|---|---|
| 大安 | 安定、平稳 |
| 留连 | 延续、牵连 |
| 速喜 | 快速、喜讯 |
| 赤口 | 言语、争执 |
| 小吉 | 小利、和合 |
| 空亡 | 空缺、未成 |

这些是便于辨认的字面联想，不代表所有体系都采用同一套定义。读到详细五行、数字、六神、方位、应期或人物象义时，应回到该段原始来源核对。

## 11.2 版本差异如何处理

本项目曾据 #112/#113 传播件整理详细道传技术表，并据其他网络材料补充细目。相关来源的许可和版本关系未核，细表、口诀及由此得出的结论已撤回。江氏官方教程电子书 #144 也仅能确认官方公告称限时免费领取，未发现整本再发布许可，因此本书不复录电子书内容。

目前可以保留的结论只有：不同作者和体系对六宫作出的配属与解释存在差别。具体差别应直接阅读获得授权或明确许可的原始页面，并标明作者、版本和日期。本章不裁定哪套解释为通说。

## 11.3 学习与记录建议

1. 每次阅读先标注体系和版本，不把不同来源的规则拼在一张表里。
2. 将原文描述、研究者摘要和个人推断分开记录。
3. 对案例保留来源与反馈，不能以单个个案证明准确性。
4. 术数内容仅作民俗文化阅读，不替代专业意见或现实证据。
