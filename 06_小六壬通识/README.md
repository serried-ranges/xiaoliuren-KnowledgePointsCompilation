# 06 小六壬通识

> 本目录＝《**小六壬通识：源流·体系·诸派**》（作者：万重山）的**成书目录**。
> 组织方式：**外层放 PDF，里面放 md／bat 等**——汇编 PDF 直接放在本目录，书稿源文件与生成工具放在 `书稿/`。

## 结构

```
06_小六壬通识/
├── 小六壬通识·合订本.pdf     ← 外层：打印生成的合订本 PDF（161 页，含书签目录）
├── 书稿/                     ← 里面：分章 md、附录、生成工具（bat/js）与审计记录
│   ├── 00_书名页（书籍信息）.md／00a_自序／00b_凡例／00c_总目录
│   ├── 01—35_第01—35章_*.md
│   ├── 99_后记与致谢（万重山）.md
│   ├── 附录A—G_*.md
│   ├── 小六壬通识·合订本.md（合并生成）
│   ├── 书稿审计记录.md
│   └── _工具_生成合订本.js／_工具_生成PDF.js／.bat／_工具_paged.polyfill.js／_工具_PDF生成说明.md
└── README.md
```

## 生成与更新

在本目录的 `书稿/` 内运行：

```
node 书稿/_工具_生成PDF.js      # 自动重建合订本 md → 分页 → 打印 PDF（输出到本目录外层）
```

（Windows 下也可双击 `书稿/_工具_生成PDF.bat`。）
