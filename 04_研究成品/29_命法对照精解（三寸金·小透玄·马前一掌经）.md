## 一、三寸金结构解析

### 1.1 月起宫表（原文→结构化）

| 生月 | 落宫 | 断辞首句 |
|---|---|---|
| 正月 | 大安 | 大安性情直，见善尊奉遇恶耻… |
| 二月 | 留恋 | 留恋运不稳，做官总将桃色混… |
| 三月 | 速喜 | 速喜闹东堂，七一九三两分张… |
| 四月 | 赤口 | 赤口有桃情，七一九三必多井… |
| 五月 | 小吉 | 小吉力多能，贵人上前去点灯… |
| 六月 | 空亡 | 空亡心聪颖，亲朋好友念善情… |
| 七月 | 大安 | 大安同父换，初年马星运渐宽… |
| 八月 | 留恋 | 留恋共潮生，重连必见双井绳… |
| 九月 | 速喜 | 速喜官不和，双亲堂前多见克… |
| 十月 | 赤口 | 赤口卧寒松，二八逢年运不通… |
| 十一月（冬月） | 小吉 | 小吉性情倔，克伐六亲有伤缺… |
| 十二月（腊月） | 空亡 | 空亡心刚强，自力更生挑家梁… |

### 1.2 关键发现：三寸金＝"生月落宫"读法

- 其宫位分配**正好就是小六壬的起月规则**（大安起正月→空亡六月→七月回大安）——即：**把"月日时起课"的第一步（月宫）单独抽出来当命盘用**。
- **同轴对照**：小六壬起课（大安起正月，月→宫）；**不同轴对照**：邵系应期"地支月份表"（宫→月：大安＝寅卯辰月）、一掌经"年上起月"（以生年定月起点）。
- 断辞主题：性格、官运、财运、婚姻（"姻缘早动""桃花"）、六亲刑克、灾咎（"无常""少亡"）——属典型**民间命课歌**。
- 术语小注："七一九三"「二七」「四九」「三八」等数字串＝民间应期/年份数用法；"重照/重连"＝同宫重见。

## 二、小透玄结构解析

### 2.1 结构（6 组 × 3 句）

| 主句 | 主题要点（摘） |
|---|---|
| 日坐大安 | 心慈祥／先克父／早坎坷晚吉昌；"速喜临时拜佛堂""时加空亡财路宽" |
| 日坐留恋 | 脚板宽走江川／心直口快不触官；"大安落位…禄马学堂捧金碗""时临小吉相貌端" |
| 日坐速喜 | 巧舌礼／婚姻分离；"做事一气不到底""三月走到空亡地，克妻不死亦各异" |
| 日坐白虎（赤口） | 性情怪／口舌快；"月日重照面多白""赤口逢克化以财" |
| 日坐小吉 | 人多情／桃红泛水；"受克小吉福不清""六亲空亡冷如冰" |
| 日坐空亡 | 财禄重／女命刚强；"空亡重照牢狱中""时临赤口在梦中" |

> **互证（第28版）**：道传"62.95MB 合集本"（御法门六卷合抄本，01 层 #157）命法卷 p83—85 载小透玄全文，与上表江说版本**同文互证**（如"日生大安…速喜临时拜佛堂""时加空亡财路宽"）；p83 另见"百句金口令"行。小透玄自此具**第二独立来源**（C 级流通件；真伪待逐页转录核验）。

### 2.2 术语与逻辑对照

| 小透玄用语 | 含义 | 邵系对应概念 | 一掌经对应 |
|---|---|---|---|
| 日坐X | 以日宫落宫为命局主语 | 体（落宫为体） | "时辰落在X星" |
| 临时X（如速喜临时） | 时辰宫位的作用 | 用（时辰为用） | —（原式以时宫为终点） |
| 重照/重连 | 月、日、时同宫重见 | 比和/伏吟之象 | 星重（犯重） |
| 受克/逢克 | 被它宫五行所制 | 制转（克） | "犯重者…" |
| 禄马学堂 | 命理吉象（禄、驿马、学堂） | — | —（纯民间命理借词） |

> 观察：小透玄与小六壬、一掌经共用一个"三/四步轮盘"，却**借用八字命理的词汇层**（禄马、学堂、桃红、刑克）——是"宫盘命理化"的口诀样本。

## 三、马前一掌经论命（本轮新证）

### 3.1 江春义自述（要点原文）

> "在民间确实流传一种**马前一掌经占命方法**，很少流传于世面，**与道家六卷占命基本相同**。可是道家六卷当初在网上传的时候没有把真正的道家六卷传出来……**没有写明白如何运用马前课占命，只写了几个口诀**。其实**马前课占命非常简单只看六亲和六宫**，与看八字理论基本相似，但要比八字简单的很多。"
> "马前一掌经论命**起法是根据当时人出生的生日时辰起盘**，断法也很简单。"
> 来源自述："我的一个**东北大仙**会马前课……她现在年纪大了也不出马看事了，所以我才有资格用。"
> （二）补充："马前断命运并非仅依据单一六宫，需**综合考虑月日时所临六宫的位置组合**来断命运，还要看**六亲所临的宫位**来看父母、兄弟姐妹、子女、事业、财运等情况。"

### 3.2 两个实例（原文摘要）

**例1（一）**：属猴者，九月十二寅时生。
> 断：子孙落在留恋——"比较贪玩，凡事不着急，慢慢腾腾。有贵人朋友来帮他，可他不争气，没有事业心……主不利官运。但还是得为了钱财而奔波，子孙落在留恋多主操劳。"

**例2（二）**：男，阴历1962年十月十八子时生（属虎）。
> 断：性格外向开朗、待人大方、思想单纯、易轻信上当、犯桃花；"比较勤快，积极努力的去赚钱"；父母落留恋——"人比较老实，但**碎嘴子**，爱叨叨……借不到父母的光"；子女——"过得比较好，在事业上也很努力"；妻子落空亡——"人品不错，比较善良，心宽"。

### 3.3 意义

- 这是**"命法卷"在民间实际样貌的第一批可核原文**：起盘＝出生月日时（与卜法同构），断法＝六亲落宫＋宫位组合——**即把占卜盘直接当命盘用**。
- 与《23》推测对照：邵系命法（推测为"年月日时四宫＋六道配宫"）与民间实践版（"月日时＋六亲"）**同源不同深**——民间版更简单（江："要比八字简单的很多"）。
- 注意：江春义称"与道家六卷占命基本相同"，同时称市面流传的（邵系）"道家六卷"没写明判法——**两系对同一卷名的所有权争论再次出现**；本包并录。

## 五、学理观察

1. **"以六宫断命"的三条轴**：月轴（三寸金）、日轴（小透玄）、全盘轴（马前一掌经）——民间把占卜盘"命盘化"的三条路径，全部可溯源到**月日时轮盘**。
2. **与六曜算法同构**：日本六曜把"月＋日"之和压入6名循环（见《19》）；三寸金把"生月"直接对应六宫——同为"择日/历注式六名循环"的思维遗存。
3. **术语层累**：书面体系（邵系）用"体用/生克"；民间口诀用"坐/临/照/克"——同一逻辑的两套话语。
4. **文献史价值**：即便归属江说系统，三寸金/小透玄/马前一掌经仍是研究"命法卷"的**首批可核原文**，填补了《16》《23》"名称级信息"的空白。
5. **待办**：寻找"一刀斩、百句金口令、铺地金、马前关煞诀"等其余命法诀文的公开线索（本轮未得）。
