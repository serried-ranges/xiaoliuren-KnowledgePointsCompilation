# 江氏断卦方法归纳（生克 · 体用 · 太极点）

> **性质**：研究层附录·速查归纳 ｜ **来源**：官方教材《江氏小六壬 官方教程（第一版）》（2024-08；来源 #144）、官站教程 1—120＋、《13 江氏体系系统提炼》 ｜ **整理日期**：2026-10-07
> 用途：把江氏断卦方法的主线压缩成可查的归纳，重点覆盖**生克、体用、太极点（用神转换）**；并与道传体系及主项目实现对照，便于开发与校对时快速定位。官方教材精校排版版见 02 层《江氏官方教程（第一版）-精校排版版》（另存主项目 `xiaoliuren/docs` 供对照）。

## 一、断卦总流程（江氏）

```
起课 → 装卦 → 取用神 → 看组合 / 生克 → 下断
```

| 步骤 | 要点 |
|---|---|
| ① 起课 | **日时**：大安起日→日上起时；**时刻**：每 10 分钟一刻；**数字**：报数÷6 取余→再起时辰。心法：有疑才占、一事不二占、第一念报数 |
| ② 装卦 | 装地支（**自身宫起**、隔位排）→ 装六亲（身宫**地支五行**为我）→ 装六神（按身宫地支查**起点表**）→ 装五星（日时用**日宫**、报数用**数字宫**、时刻用**时宫**起木火土金水空）。三条注意：先装地支、手工必须复查、"错卦错断" |
| ③ 取用神 | 七类：父母 / 兄弟 / 子孙 / 妻财 / 官鬼 / **对宫** / 自身（见 §二·4） |
| ④ 分析 | 用神所临之宫 ＋ 六神 ＋ 五星 ＋ 六亲的组合；**先看生克，再套直断口诀** |
| ⑤ 下断 | 结合问事与类象给结论（教材案例均为自证型，不作准确率证据） |

实现边界（主项目「玑衡 V3」）：江氏起课以两步定起宫、身宫；三数盘另以人宫为身、第二数宫起木星，属于扩展适配，不是教材新增的三数起课法。特定三数可与两步同盘，但方法、对象语境与对宫取法不能因此等同；公式、核验与现状见主项目 `xiaoliuren/docs/江氏小六壬起课标准与本地方案评估.md` 与 `文档/质量与审计/江氏起卦排盘现状评估与三数扩展结论.md`。当前提示词要求说明取用依据，程序尚未自动计算代问对象及转太极关系。

## 二、生克：底层运算

**1. 基础**：相生 木→火→土→金→水→木；相克 木→土→水→火→金→木。

**2. 六亲即生克**（以身宫/我为参照）：

| 关系 | 判定 |
|---|---|
| 父母 | 生我者 |
| 兄弟 | 同我者 |
| 子孙 | 我生者 |
| 妻财 | 我克者 |
| 官鬼 | 克我者 |

- **土支特例（官方确认）**：非土身宫时，从自身顺时针数到的**第一个土支**记「兄弟」，其余照生克；土身宫按普通生克即可。

**3. 六亲互生克链**：父母生兄弟 → 兄弟生子孙 → 子孙生妻财 → 妻财生官鬼 → 官鬼生父母；父母克子孙 → 子孙克官鬼 → 官鬼克兄弟 → 兄弟克妻财 → 妻财克父母。

**4. 生克的四个应用层**：

| 层 | 内容 | 备注 |
|---|---|---|
| 装卦 | 地支五行定六亲 | 土支特例见上 |
| 五星 | 五星对六亲：**生助**=吉、**克泄**=不吉；另有条件句断辞（如"木星相克不顺，见水火则吉"） | 五星为辅，不可单断 |
| 直断 | 六神临六宫/临六亲、六亲临六宫、五星临六亲等口诀——本质＝**类象 × 生克** | 口诀表见书稿 §20.9／研究包《13》§8 |
| 体用 | 中心（体）与环境（用）之间的生克 | 见 §三 |

**5. 用神七类（官方取法）**：

| 用神 | 涵盖 |
|---|---|
| 父母 | 养我庇我者：父母长辈、衣服包鞋、合同证件、工作信息等 |
| 兄弟 | 同辈：同学同事、结拜等同辈关系（主要针对人物） |
| 子孙 | 比我小者（儿女、女婿、外甥侄子）＋受我庇护者（宠物）；事：货物/能力/财源、警察/药 |
| 妻财 | 男测老婆、各种财物、财运 |
| 官鬼 | 女测老公；管制我者（官员、领导、小人）；疾病、官司、是非、纠纷 |
| **对宫** | "日时起卦的**日宫**、数字起卦的**数字宫**"——相对自己、其它宫沾不上的人和事：合作、交易、比赛、打官司、借贷、无特殊关系者 |
| 自身 | 占测自己的事，以自身所占之宫为用神 |

## 三、体用：两种表述、一个内核

| 体系 | 体 | 用 | 关系与趋势 |
|---|---|---|---|
| **江氏**（官方教材） | 所取**用神**（所问之事） | 用神所处的环境要素（其他宫位、六神、五星、时辰） | 官方教材**不使用"体用"一词**（全书 0 次）；其等价操作＝"取用神 ＋ 看用神所受生克" |
| **道传**（xiao6ren／CNB 技能） | **人宫**（落宫） | **时辰**（起卦时支） | 用生体 / 比和多吉；体生用泄气；用克体不利；体克用费力 |
| **主项目实现（玑衡 V3）** | 人宫**宫五行** | 起卦**时支五行** | 已在道传模式实现体用、时辰六亲与三宫关系（见主项目 `docs/道传排盘与 CNB 技能比对及优化方案.md`） |

> 要点：两系的"体"都是"所问之事／主体"，"用"是作用环境；区别在取值方式——江氏以**用神（太极点）**定中心，道传固定**人宫 × 时辰**。**跨体系不直接混用**（v2.2 与主项目均已在文档中声明）。

## 四、太极点与转太极（用神转换）

- **定义**：转太极＝更换"中心点（太极点）"，把用神从自身切换到对应亲属——即"用神转换"。**中心换错，全盘皆错**。
- **规则速查**（官方教材第 6 章）：

| 场景 | 规则 |
|---|---|
| 孙辈问爷爷奶奶 | 以**生父母**的地支为爷奶 |
| 外孙问姥姥姥爷 | 以**生父母**的地支为姥姥姥爷（6.8 作"生母亲"，与 6.1 冲突；以 6.1 为准，详见精校版校勘记） |
| 长辈问孙辈 | 以**子孙所生**的地支为孙辈 |
| 叔叔/姑姑、舅舅/姨母 | 与**父母同五行**的地支 |
| 先父后母 | 生我者为父，**父所克**者为母 |
| 先母后父 | 生我者为母，**克母**者为父 |
| 先爷后奶 | 生父母者为爷，**爷所克**者为奶 |
| 先奶后爷 | 生父母者为奶，**克奶**者为爷 |
| 先奶后姥 | 生父母为奶 → 父母所克为母 → **生母**者为姥 |
| 先姥后奶 | 生父母为姥 → 克父母为父 → **生父**者为奶 |
| 叔婶 | 与父母同五行为叔，**叔所克**为婶 |
| 弟妹 | 与自身同五行为弟，与弟同五行为妹（原书示例有误——"戌弟午妹"与规则不符，只引规则） |

- **与"对宫"的区别**：对宫是**特殊用神**（日宫/数字宫，主相对关系）；转太极是**换中心**（问谁就换到谁）。两者不要混用。
- **引用纪律**：教材示例多处有笔误（详见精校版文末《校勘记》），引用一律回到**规则句**。

## 五、一句话速查

- **生克**：定六亲、判五星、成口诀、入体用——一切断语的底层。
- **体用**：**中心（体）× 环境（用）**的生克方向定趋势——道传明文；江氏等价于"用神受生克"。
- **太极点**：**换中心**取准用神（问谁先换到谁）——江氏"转太极"是其在亲属占上的展开。
