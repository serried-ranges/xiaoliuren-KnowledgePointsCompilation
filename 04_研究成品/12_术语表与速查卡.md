# 小六壬 · 术语表与速查卡

> 本文件两部分：①术语表（读古籍、教程时的"名词障碍"一站解决）；②速查卡（起课、断卦、应期的一页纸流程）。

# 第一部分：术语表

## A. 基础概念

| 术语 | 释义 |
|---|---|
| **小六壬** | 又称六壬时课、诸葛马前课、掐指一算；民间掌诀占卜法，六个宫位循环。 |
| **六宫 / 六神 / 六煞** | 大安、留连、速喜、赤口、小吉、空亡六个固定宫位；或称"六神""六煞"。 |
| **掌诀** | 把推算规律简化为掌上位置与口诀的"手上算法"，又称掌诀占、掐指。 |
| **起课 / 起卦 / 装卦 / 排卦** | 得到卦（落宫、卦盘）的全过程；江氏把"排地支/六亲/六神/五星"叫装卦。 |
| **落宫** | 掐算后最后停下的宫位；传统以时宫（落宫）为结果，道传以落宫为"体"。 |
| **三宫 / 三盘** | 月宫、日宫、时宫；或称天盘、地盘、人盘。 |
| **用神** | 卦中代表"所问之事"的那组信息（宫、六亲、六神等）；"取用神"即确定它。 |
| **体 / 用** | 道传：落宫为体（结果/自身状况），时辰为用（未来趋势/外力）。 |
| **六亲** | 父母、兄弟、子孙、妻财、官鬼（＋自身）；由五行生克推演。 |
| **五行** | 金木水火土；相生相克是断卦基础。 |
| **旺相休囚死** | 五行在不同季节的力量状态（旺、相、休、囚、死）。 |
| **六十甲子** | 天干（10）与地支（12）相配的六十循环；小六壬一般只用十二地支、不用天干。 |
| **十二地支** | 子丑寅卯辰巳午未申酉戌亥；配十二时辰。 |
| **十二时辰** | 子时23—1点、丑时1—3点……每时辰2小时。 |
| **应期** | 所问之事的应验期限（何时发生）。 |
| **外应** | 起卦时看到的"不寻常现象"（声音、颜色、物件、偶遇等），作为判断参考。 |
| **错卦错断** | 若解完卦才发现卦装错了，就按错的卦断——民间认为"天意如此"。 |

## B. 道传/江氏专有

| 术语 | 释义 |
|---|---|
| **道传小六壬 / 道家小六壬** | 当代邵一尘所传体系：三宫（天地人）＋时辰，含体用、转太极等，共设想12卷。 |
| **江氏小六壬** | 江春义（江阳君）所传体系：六宫＋十二地支＋六亲＋六神＋五星，可一课多断。 |
| **四盘** | 江氏：六宫＝地盘、六亲＝人盘、六神＝神盘、五星＝天盘。 |
| **身宫** | 江氏：时辰所落之宫，代表卦主自身；以它定六亲。 |
| **装地支** | 江氏：以时辰地支落宫为准，顺时针"隔位排"地支。 |
| **隔位排** | 排地支时跳过中间的一个地支（如戌→子→寅→辰……）。 |
| **五星 / 六星 / 天空** | 江氏辅助盘：木火土金水＋"空"共六位；从日落宫起木星顺排。 |
| **转太极** | 以某一点为"我"重新旋转推演（六亲转太极、事件转太极、神煞转太极）。 |
| **三宫具象** | 道传高级技法：由三宫阴阳定八卦，再论生克"具象"。 |
| **活六神** | 近现代创新技法：让六神按规则"移动"到其他宫辅助断卦（各家做法不一）。 |
| **地支择法** | 按三宫阴阳规则给三宫配地支。 |
| **墓库应期** | 辰水土库、未木库、丑金库、戌火库；"入库取冲为应期；逢刑冲看合，逢合看冲"。 |
| **天时之法** | 道传自称：以三才成卦、以天地人三盘断事。 |
| **本气法 / 借气法** | 道传概念：靠修持灵力（本气）与靠理论推演（借气）两类预测法。 |

## C. 历史/文献

| 术语 | 释义 |
|---|---|
| **六壬** | 大六壬之名；一说得名于"天一生水、地六成之"及六十甲子中六个壬（壬子壬寅壬辰壬午壬申壬戌）。 |
| **大六壬 / 中六壬 / 小六壬** | 大六壬＝三式之一（天地盘、四课三传）；中六壬＝天罡掌诀（霍斐然说）；小六壬＝本资料主题。 |
| **马前课** | ①小六壬的俗称；②托名诸葛亮的十四课谶诗（两种含义要分清）。 |
| **六壬时课 / 李淳风六壬时课** | 《玉匣记》中所载小六壬的名称。 |
| **六曜 / 六辉** | 大安、留连、速喜、赤口、小吉、空亡；日本演变为先胜、友引、先负、佛灭、大安、赤口。 |
| **玉匣记** | 《增补许真君万全玉匣记》，小六壬（六壬时课）的主要传世载体。 |
| **上兀下兀日** | 宋代流行的择日神煞；《协纪辨方书》称"即俗传小六壬之留连、赤口日"。 |
| **兀法 / 六轮兀法 / 本命兀法** | 宋元择日法；沈括修《元丰历》选用"六轮兀"，另有个人定制版"本命兀"。 |
| **六轮经** | ①宋代择日元典（兀法）；②清代江浙用于丧葬"回煞批书"的另一种"六轮经"（勿混）。 |
| **龙母决** | 敦煌 P.3803 中与小六壬轮布相同的雏形记载。 |
| **协纪辨方书** | 清乾隆四年（1739）敕撰择吉典；批评"小六壬"用日法"尤为荒陋"。 |
| **宿曜经** | 唐不空译（759）、杨景风注的密教占星经；六曜可能的远源之一。 |
| **天罡掌诀** | 托名诸葛亮的"中六壬"；霍斐然1976年得本、1997年整理。 |
| **一掌经** | 托名唐一行的相命法；与道传小六壬"六道十二宫"相关。 |

## D. 现代/心理

| 术语 | 释义 |
|---|---|
| **巴纳姆效应** | 人容易把模糊、普遍的人格描述当作"说中自己"；六宫断语模糊，极易触发。 |
| **确认偏误** | 只记住"应验"的卦例、忽略失准案例的倾向。 |
| **决策投射工具** | 部分现代平台的自我定位：不保证命运，只帮你把心事"投影"成一个具体意象。 |
| **三不占** | 不诚不占、不疑（无疑）不占、不义不占。 |
| **算卦七不算** | 民间行业禁忌（生死寿元、胎儿性别等），属伦理惯例，非小六壬独有。 |

## 速查卡 2：起课三步（传统时间法）

```
① 起月：大安起正月 → 顺数到所求月份 → 落宫A
② 起日：从A起初一 → 顺数到所求日辰 → 落宫B
③ 起时：从B起子时 → 顺数到所求时辰 → 落宫C（答案）
       （A=月宫/大环境，B=日宫/过程，C=时宫/结果）
```

报数法：三个数从大安起接力数；或用江氏单数法（数÷6取余→起时辰）。

## 速查卡 3：断卦四步

```
① 定吉凶：看时宫（大安/速喜/小吉吉；留连/赤口/空亡凶）
② 看三宫：月→大环境，日→对方/过程，时→结果/自己
③ 论生克：三宫五行生克；体用（落宫=体，时辰=用）
④ 断细节：取类象、断应期（季节/数字/地支月/墓库）
```

体用速记：**用生体大吉，体克用小吉，比和吉；体生用小凶，用克体大凶，比劫凶。**

## 速查卡 4：分类事项快速定位（问什么看哪里）

| 问事 | 主要取用 |
|---|---|
| 自己的事 | 自身（时宫/身宫） |
| 对方/合作/交易 | 日宫（对宫） |
| 父母/长辈/文书/房子 | 父母 |
| 同辈/竞争/合作 | 兄弟 |
| 子女/宠物/财源/解灾 | 子孙 |
| 财物/男测对象 | 妻财 |
| 疾病/官司/女测对象/领导 | 官鬼 |
| 失物 | 落宫吉凶＋地宫方位＋类象（颜色/容器/环境）＋日加时断36条（14文件） |
| 行人 | 看落宫六神（速喜快、留连慢、空亡难见） |
| 时间 | 应期法（季节＋数应＋地支月＋墓库冲合） |

## 速查卡 5：应期速记

- 大安→春（寅卯辰月）、速喜→夏（巳午未）、赤口→秋（申酉戌）、小吉→冬（亥子丑）、留连→四季（辰戌丑未）、空亡→冬春（丑寅/辰戌）。
- 数字：按"谋事数"或道传"数应"推算；取年/季/月/日/时视问题而定。
- 墓库：入辰（水/土）、未（木）、丑（金）、戌（火）之库，**取冲为应期**；"逢刑冲看合，逢合看冲"。

## 速查卡 6：操作纪律（贴在墙上版）

1. 遇事即占，无事勿占；一事一占，初占为准。
2. 心诚、专注、第一念数字为准。
3. 同一时辰同一事不重占；结果不好不换时辰再占。
4. 不戏占、不试卦、不占赌博、不占国运政治、不轻断生死寿元。
5. 装卦先装地支、仔细核对；错卦错断。
6. 涉及健康/法律/投资，找专业人士；卦只作参考。
