# 小六壬 · 流派与传承谱系

> 小六壬是近代流派分化最严重的术数之一，民间号称"派系多达几十家"（江春义《浅谈数术小六壬那些事》）。本文按"主干—衍生"梳理，并给出差异对照与甄别建议。

---

## 一、总述

- 所有流派都建立在同一套**六宫循环**上：大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡（顺序永远固定不变）。
- 差异主要出现在：**起课方式**（单宫/三宫/三宫加时辰/六宫）、**用神体系**（五行、六神、地支、六亲、五星）、**断法深度**（只断吉凶 vs 一课多断）。
- 流传时间线（江春义总结）：由"马前课"→"李淳风六壬时课"→近现代"道家小六壬（三宫加时辰）"→"各翻版"→"江氏小六壬（六宫）"→"江氏衍生派系"，另有出马仙一系的"仙家马前课"。

---

## 二、主干流派

### 1. 民间马前课（单宫/三宫原型的总称）
- **来源**：民间口传、术士与"奶奶们"的传家宝；据江春义称"保守估计一千多年历史"。
- **体系**：以"落宫见吉凶"为核心，结构为天、地、人三宫顺序。
- **特点**：入门最简单、上手即用；但"只能断吉凶和一些简单问题"，被称为"乡野之术"的代表。
- **现代说法**：常与"诸葛马前课"混称。注意《马前课》另有**十四课谶诗**（预言历代兴衰），与掐指占卜是两回事。

### 2. 李淳风六壬时课（《玉匣记》版）
- **来源**：托名唐代李淳风；载于《增补许真君万全玉匣记》，有"千年历史"之说（江春义）。
- **体系**：《玉匣记》只记载了起法和用法（月→日→时三步，落宫见吉凶），**核心内容并未记载**。
- **版本**：①正常的**三宫版**（见《玉匣记》）；②**纳入十二地支和八卦的版本**，出自清末，今基本失传（江春义说）。
- **地位**：现行小六壬模式的直接来源；"六壬时课"之名即出自该书。

### 3. 道家小六壬 / 道传小六壬（邵一尘系）
- **来源**：当代易学研究者**邵一尘**所传，自称得自终南山隐士"七尘子"及"天罡六壬派第24代掌教柳明志"（六壬时课，相传为袁天罡、李淳风所传）；最初称"**道传小六壬**"，后因交流群冲突改称"**道家小六壬**"。
- **体系**：与李淳风六壬时课类似但以"天、地、人"为三宫顺序，并**加入时辰作解局参考**（变相成为"四宫小六壬"）；重视象意与逻辑性。
- **内外两版**：外部版（市场上流传）与内部版（加十二地支）。
- **十二卷设想**：邵一尘称道家小六壬全套共12卷——卜法、命法、地法、择法、香法、阴法（癔法）、解法、禁法、壬法、修法、穿法、遁法（隐法）；网上流传的"六卷"经其比对为"有故意改动"的版本。这套12卷体系包含卜法、符咒、神通等，自称"本气法与借气法相结合"。
- **技术要点**：体用关系（落宫为体、时辰为用）、三盘（起因/经过/结果）、六亲转太极、三宫具象（配八卦）、应期（四季/地支月/数字）、分类占（成败、婚情、寻物、罹病、面相、风水、天象）等。
- **著作**：《道家小六壬神通》（2009年开始撰写，2010年取名，2012年前后完成初稿）。

### 4. 江氏小六壬（江春义系）
- **来源**：江春义称祖上传承、由江氏祖上在传统小六壬基础上创建完善；长期"传内不传外"，后由其打破祖训公开。其子**江阳君**撰写《江阳君带你轻松学小六壬》系列教程（2023年起陆续发布，截至2026年已逾百篇）。
- **体系**：以**六宫**为主（非三宫），在六神基础加入**十二地支、六亲、五星（六星）、六亲主事、转太极**等，信息量大；起课用"日时／时刻／数字"三法（非传统月日时，详见04文件）；装卦依次排地支→六亲→六神→五星；采用六爻的六亲制与类似奇门的盘式，"解局更直观"，可**一课多断**、判断来龙去脉与结局。
- **四盘结构**：六宫为**地盘**，六亲为**人盘**，六神为**神盘**，五星为**天盘**（排盘顺序：先排地支→取六亲→取自身六亲）。
- **取用神**：父母/兄弟/子孙/妻财/官鬼/对宫/自身，各有取法（见06文件）。
- **身宫**：时辰落宫为身宫（代表卦主自身），以身宫地支五行定六亲。
- **官方资源**：江氏小六壬在线排盘系统（免费）。

### 5. 中国香港乐命堂"小六壬占卜深度学"（潘乐德系）
- **来源**：中国香港玄学机构乐命堂创办人**潘乐德**（港大文学士、北大国际关系硕士）系统整理，2024年发表多篇考证文章。
- **体系**：主张小六壬实为"六曜（择日体系）＋六神（大六壬天将体系）"两套系统的融合，实际是"12个卦象"；具体应用需在两套体系间自由切换；采用大六壬"三传"思维改造三宫断法；自称是**中国香港首个**系统教授小六壬占卜术的课程。

### 6. 道传小六壬的翻版（派生派系群）
江春义列举的"相似或改化而成"版本（多出现于近几年，被认为"基本和邵一尘老师的道家小六壬差不多，就是改了一些东西"）：
> 奇门小六壬、和萍小六壬、华山小六壬、刘氏小六壬、灵通小六壬、北辰小六壬、老胡道道的小六壬、何寅亥的小六壬、玄灵小六壬、邵氏小六壬、掐指神通小六壬、玄易小六壬、张氏小六壬、道法小六壬、道教小六壬、正一道家小六壬、茅山古法小六壬……不少于几十家。

### 7. 江氏小六壬的衍生

| 派生流派 | 开创/推广者 | 说明 |
|---|---|---|
| 象数小六壬 | 阡陌林海 | 由江氏小六壬改造；作者曾是江春义学生，后自立门户 |
| 仙家（氏）小六壬 | 小凤仙 | 基于江氏改造，偏重灵异断事；出马仙出身，也曾是江春义学生 |
| 仙家小六壬 / 仙家马前课 | 出马仙与民间 | 与"小凤仙"无关；多为天地人三宫、男顺女逆起局，专注灵异方向，"出马必学"，号称几百年历史 |

### 8. 中六壬·天罡掌诀（关联流派，勿混淆）
- 名称：天罡掌诀／天罡六壬神课／天罡六壬神课金口诀，**被霍斐然称为"中六壬"**。
- 出处：《诸葛天罡马前六壬时课》，霍斐然1976年11月14日得手抄本于夏明诚，1997年重新整理；其自述《天罡掌诀》录自**许逊《增广玉匣记》木刻本**。
- 体系：采用大六壬十二神将中的十将（登明、神后、大吉等，不用功曹、太冲），以"子午卯酉"论**加孟/加仲/加季**三种结论，简单快速；霍斐然称其"比大六壬简易，但仍属六壬类式"。
- 意义：说明"六壬"一名下有**大六壬、中六壬、小六壬**之分；与正统大六壬"有根本区别，不可混淆"。

### 9. 马前双留恋（十二宫体系，据江春义《江氏小六壬与其它小六壬的区别》）
- 不是单宫断卦，而是**用十二宫断卦**：把六宫分布到十二宫——寅大安、卯留连、辰速喜、巳赤口、午小吉、未空亡、申大安、酉留连、戌速喜、亥赤口、子小吉、丑空亡。
- 占卦需**分阴阳六神**，口诀繁多（号称上千条），但没有具体详细的解卦方法，所以难学。
- 与"马前课（三宫）""李淳风六壬时课""道家小六壬""江氏小六壬"并列，为一支较少见的民间变体。

### 9. 日本六曜（历注体系，非占卜体系）
- 14世纪由中国传入；演变为先胜、友引、先负、佛灭、大安、赤口；主要作为历书择日注文使用（详见01文件）。
- 对研究小六壬的"择日血统"有重要参考价值。

## 三、流派差异对照表

### 3.1 六神属性对照（通书流行版 vs 道家/道传版）

| 宫位 | 通书流行版：五行/六神 | 道传（邵一尘）版：五行/六神 | 备注 |
|---|---|---|---|
| 大安 | 木 / 青龙 | 木 / 青龙（正东，震） | 一致为主 |
| 留连 | 水 / 玄武 | 四方土 / 腾蛇（四角，巽坤乾艮） | **五行与六神均有分歧**；亦有版本作"玄武" |
| 速喜 | 火 / 朱雀 | 火 / 朱雀（正南，离） | 一致 |
| 赤口 | 金 / 白虎 | 金 / 白虎（正西，兑） | 一致 |
| 小吉 | 木 / 六合 | 水 / 玄武（正北，坎） | **五行与六神均有分歧**；亦有版本作"六合" |
| 空亡 | 土 / 勾陈 | 土 / 勾陈（中央） | 一致；个别民间版本作"玄武" |

> 说明：六神与五行的排列分歧是各流派互相"打架"的重灾区。传统通书版口诀"大安属木青龙、留连属水玄武、速喜属火朱雀、赤口属金白虎、小吉属木六合、空亡属土勾陈"流传最广；道传版则强调"留连为四方土、小吉为玄武水"并称"经过长久实践证明"。

### 3.3 体系规模对照

| 体系 | 宫数 | 附加维度 | 断法深度 |
|---|---|---|---|
| 马前课（民间） | 1宫（落宫） | 基本无 | 只断吉凶、简单事 |
| 李淳风六壬时课 | 3宫（月/日/时） | 五行、六神 | 可断事情与经过 |

### 3.4 关于"六神排列是否有误"之争

- 有民间研究者（如"奇门派"网站文章）提出：传统六神与宫位的固定配对（大安青龙→留连玄武→速喜朱雀→赤口白虎→小吉六合→空亡勾陈）"可能有误"，并给出另一套排列（赤口白虎→小吉六合→留连玄武→速喜朱雀→空亡勾陈→大安青龙），称是"依据阴阳和十二地支相合相冲原理"重新推导。
- 但主流各家（通书、道传、江氏）沿用传统固定配对，此类"改排"属少数观点；且掐算顺序（食指根→食指上→中指上→无名指上→无名指根→中指根）各家一致、不受影响。
- 结论：**视为一家之言即可**，入门请以所师承体系的排列为准。

## 四、江湖乱象与甄别建议

来自江春义、星台君等整理者的提醒（仅作资料记录）：

1. **改名自成一派**：有人学会江氏小六壬后"稍加变化、只是改个名字、改点名词就对外宣称自成一派"；也有人直接冒充江春义开班授课。
2. **拼凑资料立派**：把诸家资料拼凑、掺入其他术数体系，"编纂几个卦例就能开宗立派"（星台君）。
3. **"祖传/异人传授"话术**：动辄宣称"祖传、口传、不见书面"，往往难以验证。
4. **10分钟速成从业**：快速学完便开始不负责任的商业占卜，甚至忽悠未成年人。
5. **古籍迷信化**：把《玉匣记》等通书当"秘籍"、旧书商把残卷当"法本"卖高价。

**甄别建议**：
- 看是否交代**具体技法结构**（宫位、起课、断法逻辑），而非只讲"灵验"故事；
- 看是否承认**流派差异和历史传承**，而非自称唯一真传；
- 警惕高价"秘传"课程与"资料加密"式营销；
- 涉及健康、法律、投资问题，永远以专业人士意见为准。

## 五、给初学者的学习路径（综合各家建议）

1. **第一步（1天）**：记住六宫顺序、掌诀位置、吉凶属性；学会"农历月→日→时"三步起课（04文件）。
2. **第二步（1周）**：熟读六宫断辞与分类占，练习寻物、天气、出行等小事；体会"三吉三凶"之外的具体意象（05文件）。
3. **第三步（1个月）**：学三宫（天地人）断法与五行生克；区分"月=大环境、日=过程、时=结果"（06文件）。
4. **第四步（进阶）**：选择一个成体系的分支（道家/道传、江氏、乐命堂式三宫系统等）深入，不东拼西凑。
5. **始终**：守住 07 文件的注意事项——心诚、一事一占、不戏占、不滥用。
