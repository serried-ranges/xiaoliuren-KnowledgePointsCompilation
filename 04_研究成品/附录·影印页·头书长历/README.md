# 早稻田大学数据库图像：发布状态

早稻田大学图书馆古典籍数据库规定，未经许可不得将数据库中的图像、书目信息等用于出版物（包括电子媒体）或网站；馆方提供[图版使用申请表](https://www.wul.waseda.ac.jp/kotenseki/image_use.pdf)。

本项目尚无适用于公开发布的许可。当前工作区仍保留以下七幅从数据库复制的页面图像；在取得许可或移除这些文件前，不得提交发布：

- `01_卷上目录（一至十条）.jpg`
- `02_卷上目录（十一至十七）+六甲神将图.jpg`
- `03_卷中目录（含第十条星曜日取事）.jpg`
- `04_星曜日取事（表首）.jpg`
- `05_星曜日取事（表续）.jpg`
- `06_九星日取之事（星盘）.jpg`
- `07_鼇头长历1816补刻本·卷中目录（星空日取之事）.jpg`

官方记录页仅作为核验入口：

- [早稻田大学古典籍综合数据库](https://www.wul.waseda.ac.jp/kotenseki/)
- [早稻田大学图书馆的图版使用条件](https://www.wul.waseda.ac.jp/kotenseki/)

当前目录中的研究文字已撤回逐页图像转录和依图形成的详细判断。本轮移除图像的操作被自动审查拦截，七幅图像仍在本目录；在取得许可或完成清除前，发布门禁不通过。后续若状态变化，须重建书稿并重跑审计。
