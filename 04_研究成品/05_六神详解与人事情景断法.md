# 小六壬 · 六神详解与人事情景断法

> 六神（六宫）：**大安、留连、速喜、赤口、小吉、空亡**。三吉：大安（大吉）、速喜（中吉）、小吉（小吉）；三凶：留连（小凶）、赤口（中凶）、空亡（大凶）。
> 本文以流传最广的"通书/民间综合版"为主，道传、江氏等差异另注。

## 二、逐宫详解

### 1. 大安（大吉 · 青龙木 · 东方 · 1/5/7）

**古断辞**
> 大安事事昌，求谋在东方（一版作"求财在坤方"），失物去不远，宅舍保安康。行人身未动，病者主无妨，将军回田野，仔细好推详。

**意象**：身不动时——静卦，静止、心安、安定、吉祥。宜静不宜动；占大安**不宜主动出击**，别人来找我做事反而吉。引申：大可安心、大人安全、领导/老大/大哥大姐平安等。

**分类占**：
| 问事 | 断语 |
|---|---|
| 运势 | 运势不错、稳定成长，但不宜躁进 |
| 财富 | 求财可，但不宜扩张，宜守住旧业 |
| 感情 | 女子问顺遂；男子问稍差（稳但缺新鲜感） |
| 事业 | 工作稳定、得上司赏识，勿锋芒太露 |
| 身体 | 无大病；注意病从口入、过度操劳 |
| 神鬼 | 大安为"解灾之神"，问题不大；小孩多为自身惊吓，大人为冲犯东方之煞或土煞 |
| 行人 | 人平安，但目前不愿与你联络 |
| 失物 | 丢不远、多在家里/近处（"大安加大安，失物在家里"） |

---

### 2. 留连（小凶 · 玄武水 · 北方 · 2/8/10）

**古断辞**
> 留连事难成，求谋日未明。官事只宜缓，去者未回程。失物南方见，急讨方称心。更须防口舌，人口且平平。

**意象**：卒未归时——暗昧不明、延迟、纠缠、拖延、漫长。引申：牵连、连绵不断、藕断丝连、细水长流、留一手。道传称之为六宫中**唯一带有"不确定性"的宫**，夜占留连尤有变数。

**分类占**：
| 问事 | 断语 |
|---|---|
| 运势 | 低迷、心情不开朗、凡事受阻 |
| 财富 | 破财之卦，且常因他人影响而破财 |
| 感情 | 沟通不良、冷战、一方过于强势 |
| 事业 | 被上司盯、被扯后腿——小人之卦 |
| 身体 | 肠胃不适、精神压力大 |
| 神鬼 | 小孩被过路游魂所扰；大人冲犯女性鬼神 |
| 行人 | 人平安，但"流连忘返"迟迟不归 |
| 失物 | 失物在南方（一说北方/眼前），急寻可称心 |

---

### 3. 速喜（中吉 · 朱雀火 · 南方 · 3/6/9）

**古断辞**
> 速喜喜来临，求财向南行。失物申未午（南或西南），逢人路上寻。官事有福德，病者无祸侵。田宅六畜吉，行人有信音。

**意象**：人便至时——快速、喜庆、吉利，指时机已到、刻不容缓。道传提醒：其火"迅猛、一烧即过"，**好事来得快但不长久**，忌拖延。

**分类占**：
| 问事 | 断语 |
|---|---|
| 运势 | 运势渐开，积极行动即可如愿 |
| 财富 | 可得；但有先破后得/先得后破之象，得财宜速脱身 |
| 感情 | 新关系为热恋；长期关系则易出口舌 |
| 事业 | 工作得利，但注意文件上的疏失 |
| 身体 | 心、血、眼、脑、头部问题，多不严重 |
| 神鬼 | 小孩被动物吓到或女性阴神冲犯；大人冲犯男性鬼神 |
| 行人 | 人快到了 |
| 失物 | 申未午时位、南或西南方寻找 |

---

### 4. 赤口（中凶 · 白虎金 · 西方 · 4/7/10）

**古断辞**
> 赤口主口舌，官非切要防。失物急去寻，行人有惊慌。鸡犬多作怪，病者出西方。更须防咒诅，恐怕染瘟殃。

**意象**：官事凶时——不吉、惊恐、凶险、口舌是非。道传称其为"伤人之虎"：断出行多是车祸等意外，断生意多为破财与纠纷——**有时比空亡还凶**。

**分类占**：
| 问事 | 断语 |
|---|---|
| 运势 | 运势不明；大计划须尽快实施可成，小事不成 |
| 财富 | 大起大落之财，求财不易 |
| 感情 | 纷争多（口舌、争吵） |
| 事业 | 武职/粗重行业（军警、体力、动手行业）顺；文职不顺 |
| 身体 | 肺、支气管、血光之灾；也主流行疾病 |
| 神鬼 | 冲犯择日凶神，或被人诅咒索害 |
| 行人 | 所问之人目前有困难或事情纠缠 |
| 失物 | 急去寻；方向一说东南/西南，一说正西 |

---

### 5. 小吉（小吉 · 六合木 · 和合 · 1/5/7）

**古断辞**
> 小吉最吉昌，路上好商量。阴人（一版作"阳人"）来报喜，失物在坤方。行人立便至，交易甚是强。凡事皆和合，病者祈上苍。

**意象**：人来喜时——和合、吉利、小确幸、有贵人相助。介于大安与速喜之间：比大安少一分"大吉"，比速喜慢一分"迅速"，且需自己努力（道传："水被木泄，付出多回报少，所以只叫小吉"）。

**分类占**：
| 问事 | 断语 |
|---|---|
| 运势 | 不错，保持现状会越来越好 |
| 财富 | 可得，且有"因人得财"（贵人/介绍）之象 |
| 感情 | 没对象的可经人介绍；有对象的恋情顺利 |
| 事业 | 工作不错；注意公司财务之事与下属沟通 |
| 身体 | 肝胆与消化系统，问题不大 |
| 神鬼 | 小孩被动物吓到或女性阴神冲犯；大人冲犯家中祖先 |
| 行人 | 快到了 |
| 失物 | 坤方（西南） |

---

### 6. 空亡（大凶 · 勾陈土 · 中央 · 3/6/9）

**古断辞**
> 空亡事不祥（一版作"事不长"），阴人多乖张。求财无利益，行人有灾殃。失物寻不见，官事有刑伤。病人逢暗鬼，禳解（一版作"析解"）保平安。

**意象**：音信稀时——不吉、无结果、忧虑、落空、徒劳、期待落空。民间注解更狠："空亡大凶，百事不可为，凡事不成，忌数4、6、8，必破财、必败、必衰、撤职、下降、牢狱之灾。"也有人直接把空亡理解为一个**很实在的"不行/No"**。

**分类占**：
| 问事 | 断语 |
|---|---|
| 运势 | 不佳，自己拿不定主意，多听他人意见，勿随意判断 |
| 财富 | 求财难得，保守为上 |
| 感情 | 争执多，常有他人介入 |
| 事业 | 工作失利，容易被人陷害或暗中耳语 |
| 身体 | 脾胃、神经系统；也有"灵界致病"之说 |
| 神鬼 | 家中阳宅或阴宅出问题导致冲犯 |
| 行人 | 途中遇困难或灾厄，难到 |
| 失物 | "寻不见"——大概率找不回 |

## 三、断辞变通三法（学小六壬的关键）

民间整理者（如台湾玥沣）总结："论卦要有澄静的心与诚恳的心，不要有游戏心态，解析时要活活泼泼。"具体变通：

1. **格局名称变通**：
   - 大安＝大可安心、大人安全、领导安全、老大/大哥/大姐安全……
   - 留连＝牵连、连绵不断、纠缠绵绵、留了一面、藕断丝连……
   - 速喜＝有喜事、喜来临、快快起（谐音）、立即起……
   - 赤口＝口舌是非、"七个口"、一起走（谐音）、赤色之口、张口争吵……
   - 小吉＝好吉利、多吉、小姐吉、小事吉利、小有吉利……
   - 空亡＝空欢喜、空望、劳而无功、一事无成、空手无望、亏损无望……
2. **象数变通**：如"一、五、七"可解为1点/5点/7点、1个/5个/7个、一个/五个/七个时辰、157分等；断数字同理。
3. **断辞变通**：断辞要结合所问之事套用，如"失物去不远"可套"问题不大、损失有限"，"行人立便至"可套"消息马上到"。

## 四、道传补充：六神藏干诀与五行细论

**六神藏干诀（师传口诀）**
> 甲居大安戊居空，大安藏丁空藏乙；
> 丙火辛金在速喜，留连丁火并己土；
> 赤口庚金生癸水，小吉壬水甲木漂；
> 天干排定宫位起，金木水火土星全。
> 火遇白虎犯官气，忧心连连婚不吉；
> 木逢留连桃花迷，破财小人暗地语；
> 土落空亡有官欺，必要破财不须疑；
> 水见白虎盗官气，金见留连婚必离。
> 大安忠厚能当官，小吉命中犯桃花；
> 留连为财劳心端，赤口之人婚不安；
> 速喜靠嘴走江川，空亡财源心路宽。
> 六神天干须分清，阴阳之理来辩明；
> 吉凶祸福切莫定，六神五行旺衰看；
> 五行生克制化机，尽在掌中起风云。

**道传版五行/方位细化**：
- 大安：正东、震、阳木、春、寅卯辰月、数1/4/5（"睡龙"，吉而偏静、缺少主动）；
- 留连：四角（巽坤乾艮）、四方阴土、四季（丑辰未戌）、数2/7/8（"拐弯转角"，缓慢、停滞、暗昧、纠缠，唯一有变数之宫）；
- 速喜：正南、离、火、夏、巳午未月、数3/6/9（火爆迅猛、后劲不足）；
- 赤口：正西、兑、金、秋、申酉戌月、数4/1/2（白虎伤人之象，主凶险、官非、争斗）；
- 小吉：正北、坎、水、冬、亥子丑月、数5/3/8（溪流之水，吉而力小，需努力；亦为"驿马/桃花"）；
- 空亡：中央、勾陈土、不在四季、数6/5/10（中空之位，主空亡、牢狱、死亡、精神病等凶象；但"外在为阳、内在为阴"，并非绝对全凶）。

**道传"六神十二宫"（每宫一隐一显两宫）**

| 六神 | 神煞 | 外在动宫 | 内在静宫 |
|---|---|---|---|
| 大安 | 青龙 | 事业宫（官学） | 命宫 |
| 留连 | 腾蛇 | 田宅宫（钱财阴私） | 奴仆宫 |
| 速喜 | 朱雀 | 感情宫（婚姻信息） | 夫妻宫 |
| 赤口 | 白虎 | 疾厄宫（灾祸官非） | 兄弟宫 |
| 小吉 | 六合/玄武 | 驿马宫（出行合作） | 子女宫 |
| 空亡 | 勾陈 | 福德宫（阴德牢狱） | 父母宫 |

**六道十二宫（与《一掌经》关联，简介）**：大安人道（天权）、留连修罗道（天奸）、速喜佛道（天贵）、赤口畜生道（天刃）、小吉仙道（天文）、空亡鬼道（天厄）——道传称与《一掌经》"绝大多数相同"，用于命法层面。

## 五、组合断法：日加时断

当时间起课得到"日宫＋时宫"两个落点时，民间有大量**两宫组合断辞**（6×6＝36组；传世通用口诀30条，寻物类另有完整36条）。**完整的36条总表见《14_日加时断完整表（36条）与组合口诀》**，以下保留精选示例（前为日宫、后为时宫）：

**（一）寻物口诀（完整36条，前日宫后时宫）**
> 大安加大安，失物在家里。大安加留连，失物西北去。大安加速喜，失物当日见。大安加赤口，失物不用找。大安加小吉，失物不出门。大安加空亡，失物无踪影。
> 留连加大安，物在家中藏。留连加速喜，失物三天里。留连加赤口，失物准丢失。留连加小吉，失物东南去。留连加空亡，失物不见面。留连加留连，失物落在南。
> 速喜加赤口，失物往正北。速喜加小吉，失物在家里。速喜加空亡，失物不久见。速喜加大安，失物不丢失。速喜加留连，失物无信息。速喜加速喜，失物落正南。
> 赤口加小吉，失物无信息。赤口加空亡，失物不用找。赤口加大安，失物东北找。赤口加留连，失物不回还。赤口加速喜，失物有着落。赤口加赤口，失物正西找。
> 小吉加空亡，失物正东找。小吉加大安，失物自己出。小吉加留连，失物上西南。小吉加速喜，失物在院里。小吉加赤口，失物丢了手。小吉加小吉，失物在西南。
> 空亡加大安，失物反复间。空亡加留连，失物永不还。空亡加速喜，失物在家里。空亡加赤口，失物往远走。空亡加小吉，失物回家里。空亡加空亡，失物寻不见。

**（二）通用日加时断选录（完整表见14文件）**
- 留连＋大安：办事两分张，婚姻有喜事，先苦后来甜。
- 留连＋速喜：事事由自己，婚姻有成意，失物三天里。
- 留连＋赤口：病者死人口，失物准丢失，婚姻两分手。
- 留连＋小吉：事事不用提，失物东南去，病者出人齐。
- 留连＋空亡：病人准死亡，失物不见面，婚姻两分张。
- 小吉＋空亡：病人不妥当，失物正东找，婚姻再想想。
- 小吉＋大安：事事两周全，婚姻当日定，失物自己损。
- 空亡＋大安：事事不周全，婚姻从和好，失物反复间。
- 空亡＋留连：办事处处难，婚姻重新定，失物永不还。
- 空亡＋速喜：事事怨自己，婚姻有一定，失物在家里。

> 使用提醒：组合断辞是民间韵文，各家版本文字有出入，宜理解其"意象方向"而非死背字面。

**（三）民间"法断"举例（分类断法示意）**
以空亡为例（出《铜口乱断》整理）：
- 寻人法断：空亡出外方。／失物法断：空亡路旁中央。／病人法断：空亡到底是空亡。／行人法断：空亡即世亡。／官非法断：空亡即不妨。／赌博法断：空亡本无收。
同理各宫都有"寻人、失物、病人、行人、官非、赌博"六类法断口诀——这是民间先生"一口断"的速查表，可自行搜集对照。

## 六、六神落位与环境（补充）

- **三吉三凶是大方向**：大安、速喜、小吉偏吉；留连、赤口、空亡偏不顺。但具体吉凶还要看**所问何事**（如赤口问武职反而顺、诉讼律师靠是非生财；速喜好事不长久；小吉利"小"不利"大"）。
- **六神对照现实场景**（民间比喻）：
  - 大安＝稳、平安，适合慢慢来；
  - 留连＝卡住、拖延，去办事会等很久；
  - 速喜＝快、好消息，适合冲刺、做决定；
  - 赤口＝吵架、是非，容易遇到冲突、车况出问题；
  - 小吉＝小确幸、贵人，有意外的收获；
  - 空亡＝落空、白忙，干脆先休息。

## 七、道家/道传"六宫类象"摘要（择要）

- **大安**：安泰、吉祥，主仁；喜时俊秀洒脱、正直大方；凶时缺乏主动、懒惰固执。主木，为树木、花卉、木质物、静物、家具；为肝胆、四肢、左腿；为家宅、卧室、床、尊贵、婚姻合美。
- **留连**：纠缠、迟缓，主虚；喜时精明谨慎、稳重多愁；凶时优柔寡断、多疑善妒。主土，为田园、沟渠、土旁姓氏、黄黑色；为脾胃、思绪、恋爱、阴雨天、大雾；为小人、阴人、虚病、邪病、慢性病。
- **速喜**：快速、喜庆，主礼；喜时心直口快、能言善辩、热情大方；凶时急躁、喜怒无常、奢侈浪费。主火，为日、烟火、炉灶、红色；为目、脑、心血、中女；为贵人、文书、喜讯、喜鹊；病为心脑血管。
- **赤口**：官伤、口舌，主义；喜时刚强果断、豪爽义气；凶时争强好胜、冒失冲动。主金，为刀剑、虎狼、金属物、银白色；为口、肺、右臂、官司、伤灾、手术；为猛禽；春夏雷雨、秋冬冰雹。
- **小吉**：小利、吉庆，主智；喜时聪明伶俐、人脉广、适应力强；凶时随心所欲、风流浪漫、投机取巧。主水，为小溪、流水、水中物、黑色；为迁移、旅游、奔波、桃花、色情；为肾、生殖器、右腿、水路。
- **空亡**：无果、没有，主信；喜时诚实守信、心胸宽厚；凶时孤僻倔强、迟钝。主土，为空室、牢房、墓穴、旷野、黄色；为落空、死亡、精神病、妄想、遗忘；为阴天多云、音信渺茫。
