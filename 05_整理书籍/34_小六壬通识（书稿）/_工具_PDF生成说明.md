# 《小六壬通识》PDF 生成方案（说明文档）

> 用途：把书稿合订本一键生成 PDF，并说明**方案原理、依赖、用法、排错与维护方式**，便于后续反复调用与执行。
> 位置：`05_整理书籍/34_小六壬通识（书稿）/`｜版本：2026-10-05（初版；同日随书稿移至 05 整编书籍层）。

## 一、产物

| 文件 | 说明 |
|---|---|
| `小六壬通识·合订本.pdf` | **最终 PDF**（A4、含封面、章起新页、表格/引用框排版；约 142 页） |
| `小六壬通识·合订本.md` | 合并源文件（由脚本自动重新生成，含章级锚点与目录跳转，**无需手改**） |
| `_工具_生成PDF.js` | 生成脚本（零第三方依赖） |
| `_工具_生成PDF.bat` | Windows 一键运行（双击即可） |

## 二、方案原理（三步流水线）

```
书稿各章 md ──(_工具_生成合订本.js)──▶ 合订本 md（注入 <a name="chNN/appX"> 锚点、目录改文档内跳转）
      ──(生成脚本内置转换器：MD→HTML＋排版 CSS)──▶ 中间 HTML（系统临时目录）
      ──(Edge/Chrome 无头模式 --print-to-pdf)──▶ 合订本 PDF
```

**为什么这样设计**：

- **不依赖 Pandoc/LaTeX/Word**——只用本机几乎必有的 Node.js 与 Edge/Chrome，避免安装链；中文排版天然无字体配置烦恼；
- **零 npm 依赖**——脚本内置了一个覆盖本书全部语法的迷你 Markdown 转换器（标题/表格/引用框/列表/代码块/链接/锚点），不会因为网络或包版本失效；
- **目录可跳转**——分章浏览时目录链接各章文件；合订本内目录改为**章级锚点跳转**（`#chNN`／`#appX`）；锚点行在 PDF 转换中透传保留；
- **单章增改即全量同步**——脚本每次运行都先调用 `_工具_生成合订本.js` 重建合订本，再转 PDF。

## 三、依赖

| 依赖 | 要求 | 备注 |
|---|---|---|
| Node.js | ≥ 16（建议 18+） | 本机 v24 已验证 |
| 浏览器 | Microsoft Edge 或 Google Chrome | 自动查找常见安装路径 |
| 字体 | 系统自带中文字体 | 默认微软雅黑；可在脚本 CSS 中改字体列表 |

可选环境变量（一般不需要）：

```
PDF_BROWSER=D:\某处\msedge.exe   # 手动指定浏览器
KEEP_HTML=1                      # 保留中间 HTML（调试排版用）
```

## 四、使用方法

**方式一（推荐·双击运行）**：双击 `_工具_生成PDF.bat`。

**方式二（命令行）**：在本文件夹执行

```
node _工具_生成PDF.js
```

**方式三（从仓库根目录）**：

```
node "05_整理书籍/34_小六壬通识（书稿）/_工具_生成PDF.js"
```

预期输出：`✓ PDF 已生成：小六壬通识·合订本.pdf（约 X MB，格式校验通过）`。

## 五、常见修改点

| 想改什么 | 改哪里（`_工具_生成PDF.js`） |
|---|---|
| 字号/行距/页边距 | `css` 中的 `@page`、`body`、`p` 规则 |
| 章起新页 / 表格样式 / 引用框颜色 | `css` 中 `h1`、`table`、`blockquote` 规则 |
| 封面文字 | `html` 模板中的 `section.cover` |
| 输出文件名 | 常量 `OUT_PDF` |
| 正文字体 | `css` 里 `font-family` 列表（把想用的字体放最前） |

> 注意：合订本 md 是**自动生成**的，不要直接手改；增删改内容请改单章文件，再运行本脚本。

## 六、排错

| 现象 | 处理 |
|---|---|
| 提示"未找到 Edge/Chrome" | 安装 Edge；或设 `PDF_BROWSER` 指向浏览器 exe；或手动打开中间 HTML 用"打印→另存为 PDF" |
| PDF 里中文显示为方框 | 在 `css` 的 `font-family` 里加入本机已有中文字体（如"Microsoft YaHei"） |
| 想保留中间 HTML 检查排版 | 设 `KEEP_HTML=1` 后运行，HTML 在系统临时目录 |
| 生成失败且无提示 | 浏览器可能被旧版占用/版本过旧；先完全退出浏览器再试，或升级 Edge |
| 表格跨页断得难看 | 已设 `tr { page-break-inside: avoid }`；如需整表不断页，给 `table` 加 `page-break-inside: avoid`（长表慎用） |
| 合订本里目录不跳转 | 确认先运行了 `_工具_生成合订本.js`（本 PDF 脚本会自动先跑）；锚点形如 `<a name="ch01"></a>` |

## 七、维护约定（与书稿/审计的关系）

1. **标准更新流程**：改单章 → 运行 `_工具_生成PDF.js`（自动重建合订本并出 PDF）→ 跑双审计（`04_研究成品/附录·审计工具/audit.js` 与 `content_audit.js`）；
2. PDF 与合订本 md 均为**派生文件**，双审计不重复扫描；《书稿审计记录》亦为元文档、不参与扫描；
3. 生成方案或排版规则如有调整，请同步更新本说明文档的版本信息；
4. 仓库换机器重新生成时，只需要 Node + Edge/Chrome 两个条件。
