## 速查卡 2：起课三步（传统时间法）

```
① 起月：大安起正月 → 顺数到所求月份 → 落宫A
② 起日：从A起初一 → 顺数到所求日辰 → 落宫B
③ 起时：从B起子时 → 顺数到所求时辰 → 落宫C（答案）
        （A=月宫/大环境，B=日宫/过程，C=时宫/结果）
```

报数法：三个数从大安起接力数；或用江氏单数法（数÷6取余→起时辰）。**落宫算第 1 数。**

## 速查卡 3：断卦四步

```
① 定吉凶：看时宫（大安/速喜/小吉吉；留连/赤口/空亡凶）
② 看三宫：月→大环境，日→对方/过程，时→结果/自己
③ 论生克：三宫五行生克；体用（落宫=体，时辰=用）
④ 断细节：取类象、断应期（季节/数字/地支月/墓库）
```

体用速记：**用生体大吉，体克用小吉，比和吉；体生用小凶，用克体大凶，比劫凶。**

## 速查卡 5：应期速记

- 大安→春（寅卯辰月）、速喜→夏（巳午未）、赤口→秋（申酉戌）、小吉→冬（亥子丑）、留连→四季（辰戌丑未）、空亡→冬春（丑寅/辰戌）；
- 数字：按"谋事数"或道传"数应"推算；取年/季/月/日/时视问题而定；
- 墓库：入辰（水/土）、未（木）、丑（金）、戌（火）之库，**取冲为应期**；"逢刑冲看合，逢合看冲"。

## 速查卡 6：操作纪律（贴在墙上版）

1. 遇事即占，无事勿占；一事一占，初占为准。
2. 心诚、专注、第一念数字为准。
3. 同一时辰同一事不重占；结果不好不换时辰再占。
4. 不戏占、不试卦、不占赌博、不占国运政治、不轻断生死寿元。
5. 装卦先装地支、仔细核对；错卦错断。
6. 涉及健康/法律/投资，找专业人士；卦只作文化参考。
