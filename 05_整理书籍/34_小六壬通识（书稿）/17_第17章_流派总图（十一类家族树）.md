# 第17章　流派总图：十一类家族树

> **本章导读**：小六壬是近代流派分化最严重的术数之一，民间号称"派系多达几十家"。但万变不离其宗：所有流派都建立在**同一套六宫循环**上。这一章先画一张全景图——谁是谁、谁从谁来、谁和谁不能混。

## 17.1 一句话总述

所有流派的共同底盘：**六宫永远固定**——大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡（顺序不可变）。

分化出现在三个层面：

1. **起课方式**：单宫／三宫／三宫加时辰／六宫装卦；
2. **用神体系**：五行、六神、地支、六亲、五星；
3. **断法深度**：只断吉凶 vs 一课多断。

传统的流传顺序（据江春义总结）：

> 马前课 → 李淳风六壬时课 → 近现代"道家小六壬（三宫加时辰）" → 各翻版 → 江氏小六壬（六宫） → 江氏衍生派系；另有出马仙一系的"仙家马前课"。

## 17.3 四层名号：先记住这张"身份证"

初学最容易晕的不是技法，而是**名号**——"道传""道家""道家马前""江氏"四个词，分属不同的体系。按时间捋成四层：

```
传统马前课（民间口传）
   ├─ ① 李淳风六壬时课（《玉匣记》·三宫）
   ├─ ② "道家马前小六壬"（江春义所述·民间秘传六卷）
   └─ ③ 道传小六壬＝道家小六壬（邵一尘系·十二卷叙述·2011公开）
④ 江氏小六壬（江春义本门·六宫装卦）——另一条独立传承线
```

> ⚠️ **分歧 8｜名号之争：谁才是"道家小六壬"**
> - 邵系材料中"道传""道家"两名并用，指同一体系（邵一尘整理公开）；
> - 江春义另述"**道家马前小六壬**"六卷，并称市面上流传的"道家小六壬"（邵系）"并不是真正的……而是东拼西凑后的"；
> - **两说并存，本书不裁定**——此为竞争体系间的名号之争。实用判别法：看**内容特征**——讲"三盘天地人、体用、转太极、三宫具象"，即邵系；讲"装地支、装六亲、五星、取用神、对宫"，即江氏；讲"武沐浴书、鬼门十三针"等马前秘传内容，即江说的道家马前（详见附录 F）。

## 17.4 这张图怎么用：三条阅读纪律

1. **贴标签阅读**：任何一篇小六壬文章，先判断它属于传统／道传（邵系）／江氏／道家马前／其他哪一家，再看它的五行、数字、起课与你所学是否一致；
2. **不混用**：五行、数字、六神起点各家互不通用；跨体系"借技法"必须注明来源；
3. **选题对路**：想快断吉凶→传统口诀；想细断来龙去脉（象意型）→道传系；想一事多断、关系网清晰（装卦型）→江氏。

## 本章要点

- 所有流派共用同一六宫循环；分化在起课、用神、断法深度三处。
- 十一类家族树：传统底层／传统主干／当代主干①道传②江氏／新说／民间变体／关联流派／历注／衍生群／市场商品。
- 名号四层：玉匣记（六壬时课）、道家马前（江说六卷）、道传＝道家（邵系）、江氏——按内容特征判别。
