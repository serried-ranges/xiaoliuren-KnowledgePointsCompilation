# 第4章　六宫速览（三吉三凶）

> **本章导读**：六个宫各主什么吉凶、什么物象？这一章给出每一宫的"名片"：古断辞、核心意象与分类速览。读完它，你对一课结果的"第一反应"就有了底子。
>
> **阅读前提醒**：本章所录断辞均为旧时韵文**原文**，含旧时代话语与疾病的传统旧说，仅作历史与民俗文本阅读，不构成任何现实建议；身体类内容一律不是医学结论，健康问题请就医。

## 4.1 一张总表

先看流传最广的"通书流行版"速览表（数字、五行等另有版本差异，见本节末分歧框）：

| 宫位 | 吉凶 | 五行 | 方位 | 六神 | 谋事数 | 一句话意象 |
|---|---|---|---|---|---|---|
| 大安 | 大吉 | 木 | 东 | 青龙 | 1、5、7 | 身不动——平安、稳定，宜静 |
| 留连 | 小凶 | 水 | 北 | 玄武 | 2、8、10 | 卒未归——拖延、纠缠、反复 |
| 速喜 | 中吉 | 火 | 南 | 朱雀 | 3、6、9 | 人便至——喜讯快来、迅速 |
| 赤口 | 中凶 | 金 | 西 | 白虎 | 4、7、10 | 官事凶——口舌是非、惊险 |
| 小吉 | 小吉 | 木 | 和合 | 六合 | 1、5、7 | 人来喜——和合顺利、小成 |
| 空亡 | 大凶 | 土 | 中央 | 勾陈 | 3、6、9 | 音信稀——落空无果、谋事不成 |

> ⚠️ **分歧 3 / 4 / 6｜五行、六神与数字的版本差异**
> - **五行**：道传（邵系）版作"留连属四方土、小吉属水"；江氏体系以地支装卦为主，社区实现近道传版；
> - **六神**：道传版作"留连临腾蛇、小吉临玄武"；江氏装卦另按身宫地支起青龙排六神；
> - **数字**：道传另有一套"数应＋隐藏数"（大安 1·4·5 等），民间还有"成数/忌数"一套。
> - **诸说并存，本书不裁定**——对照与出处详见第 11、22 章与附录 F。

## 4.2 逐宫速览

以下每宫，先列**古断辞**（通书版原文），再讲**核心意象**，最后是**分类速览**（民间综合版的通行断语）。断辞文字各版本略有出入，逐句校勘见第 24 章。

### 4.2.1 大安（大吉 · 青龙木 · 东方 · 1/5/7）

> **古断辞**：大安事事昌，求谋在东方（一版作"求财在坤方"），失物去不远，宅舍保安康。行人身未动，病者主无妨，将军回田野，仔细好推详。

**核心意象**：**身不动时**——静卦：安定、吉祥、稳。宜静不宜动；占得大安，传统讲究"不主动出击"，别人主动来找反倒好。引申义很活：大可安心、大人安全、领导/长辈平安。

**分类速览**：

| 问事 | 通行断语 |
|---|---|
| 运势 | 稳定成长，但不宜躁进 |
| 财富 | 求财可，宜守旧业、不宜扩张 |
| 感情 | 稳而无波——女问偏顺，男问稍平（缺新鲜感） |
| 事业 | 稳定、得上司赏识；勿锋芒太露 |
| 身体 | 传统类象归四肢、肝胆（非医学结论） |
| 行人 | 人平安，但眼下不愿与你联络 |
| 失物 | 丢不远，多在家中或近处（"大安加大安，失物在家里"） |

*道传补记：大安为"睡龙"——吉而偏静、缺少主动；正东、震、阳木、春。*

### 4.2.2 留连（小凶 · 玄武水 · 北方 · 2/8/10）

> **古断辞**：留连事难成，求谋日未明。官事只宜缓，去者未回程。失物南方见，急讨方称心。更须防口舌，人口且平平。

**核心意象**：**卒未归时**——暗昧不明、延迟、纠缠、漫长。引申为牵连不断、藕断丝连、细水长流。道传称它是六宫中**唯一带"不确定性"的宫**，夜里占得尤其"有变数"。

**分类速览**：

| 问事 | 通行断语 |
|---|---|
| 运势 | 低迷、心情不开朗、凡事受阻 |
| 财富 | 破财之卦，且常因他人影响而破 |
| 感情 | 沟通不良、冷战、一方过于强势 |
| 事业 | 被上司盯、被扯后腿——"小人之卦" |
| 身体 | 传统类象归肠胃、思绪与压力（非医学结论） |
| 行人 | 人平安，但"流连忘返"迟迟不归 |
| 失物 | 南方（一说北方或眼前），急寻可称心 |

*道传补记：留连为"四方土"，对应四角与四季之末（丑辰未戌），临腾蛇；主缓慢、停滞、暗昧。*

### 4.2.3 速喜（中吉 · 朱雀火 · 南方 · 3/6/9）

> **古断辞**：速喜喜来临，求财向南行。失物申未午（南或西南），逢人路上寻。官事有福德，病者无祸侵。田宅六畜吉，行人有信音。

**核心意象**：**人便至时**——快速、喜庆、时机已到。道传提醒：它的火"迅猛、一烧即过"——**好事来得快，但不长久**，最忌拖延。

**分类速览**：

| 问事 | 通行断语 |
|---|---|
| 运势 | 运势渐开，积极行动即可如愿 |
| 财富 | 可得，但有"先破后得/先得后破"之象，得财宜速脱身 |
| 感情 | 新关系为热恋；长期关系易生口舌 |
| 事业 | 工作得利，注意文件疏失 |
| 身体 | 传统类象归心、血、眼、脑（非医学结论） |
| 行人 | 人快到了 |
| 失物 | 朝申未午之时位、南方或西南方寻找 |

*道传补记：速喜正南、离火、夏；火爆迅猛、后劲不足。*

### 4.2.4 赤口（中凶 · 白虎金 · 西方 · 4/7/10）

> **古断辞**：赤口主口舌，官非切要防。失物急去寻，行人有惊慌。鸡犬多作怪，病者出西方。更须防咒诅，恐怕染瘟殃。

**核心意象**：**官事凶时**——口舌是非、惊恐、官非。道传称其为"伤人之虎"：问出行多意外之象，问生意多破财纠纷——**有时比空亡还凶**。

**分类速览**：

| 问事 | 通行断语 |
|---|---|
| 运势 | 大势不明；大计划尽快实施可成，小事不成 |
| 财富 | 大起大落之财，求财不易 |
| 感情 | 纷争多——口舌、争吵 |
| 事业 | 武职与"动手"的行当（军警、体力、技术）偏顺；文职多不顺 |
| 身体 | 传统类象归肺、呼吸（非医学结论） |
| 行人 | 对方眼下有困难或事情纠缠 |
| 失物 | 急去寻；方向一说东南/西南，一说正西 |

*道传补记：赤口正西、兑金、秋；白虎伤人之象，主凶险、官非、争斗。*

### 4.2.5 小吉（小吉 · 六合木 · 和合 · 1/5/7）

> **古断辞**：小吉最吉昌，路上好商量。阴人（一版作"阳人"）来报喜，失物在坤方。行人立便至，交易甚是强。凡事皆和合，病者祈上苍。

**核心意象**：**人来喜时**——和合、吉利、小确幸、有贵人助。它介于大安与速喜之间：比大安少一分"大吉"，比速喜慢一分"迅速"，而且**需要自己出一把力**（道传的说法：水被木泄，付出多回报少，所以只叫"小吉"）。

**分类速览**：

| 问事 | 通行断语 |
|---|---|
| 运势 | 不错，保持现状会越来越好 |
| 财富 | 可得，且有"因人得财"之象（贵人、介绍） |
| 感情 | 单身者多经人介绍；有伴者恋情顺利 |
| 事业 | 工作不错；注意公司财务与下属沟通 |
| 身体 | 传统类象归肝胆、消化（非医学结论） |
| 行人 | 快到了 |
| 失物 | 西南方（坤方） |

*道传补记：小吉作"正北坎水"（一说仍作六合木），溪流之水——吉而力小，需努力；亦为驿马、桃花之象。*

### 4.2.6 空亡（大凶 · 勾陈土 · 中央 · 3/6/9）

> **古断辞**：空亡事不祥（一版作"事不长"），阴人多乖张。求财无利益，行人有灾殃。失物寻不见，官事有刑伤。病人逢暗鬼，禳解（一版作"析解"）保平安。

**核心意象**：**音信稀时**——落空、无结果、忧虑、徒劳、期待落空。民间注解更狠，也有整理者干脆把它理解为一个很实在的"**不行 / No**"。

**分类速览**：

| 问事 | 通行断语 |
|---|---|
| 运势 | 不佳，自己拿不定主意，多听他人意见 |
| 财富 | 求财难得，保守为上 |
| 感情 | 争执多，常有他人介入 |
| 事业 | 工作失利，易被暗算或暗中非议 |
| 身体 | 传统类象归脾胃、神经系统（非医学结论） |
| 行人 | 途中遇困难，难到 |
| 失物 | "寻不见"——大概率找不回 |

*道传补记：空亡为中央勾陈土、"中空之位"；道传特意指出它"外在为阳、内在为阴"，并非绝对全凶。*

> **排查说明**：各宫在民间还配有"神鬼类"断法（冲犯、游魂、宅舍之类），属民俗信仰内容。按本书门禁，只作名称级记录，不展开、不提供任何操作。
> 断辞中的"禳解"等旧时说法，属民俗信仰语汇，本书同样只作历史文本标注。

## 4.3 断辞变通三法（学小六壬的关键）

老断辞是韵文，认死字面就会闹笑话。民间整理者总结的变通三法是：

1. **格局名称变通**——把宫名拆开活用：
   - 大安＝大可安心、大人安全、领导安全……
   - 留连＝牵连、连绵不断、藕断丝连、留一手……
   - 速喜＝有喜事、喜来临、快快起（谐音）、立即起……
   - 赤口＝口舌是非、赤色之口、张口争吵、一起走（谐音）……
   - 小吉＝好吉利、小姐吉、小事吉利、小有吉利……
   - 空亡＝空欢喜、空望、劳而无功、一事无成、空手无望……
2. **象数变通**——"一、五、七"可以是一点、五点、七点，也可以是一个、五个、七个，还可以是 157 分、1.57 米……随所问之事而定；
3. **断辞变通**——把断辞往所问的事上套：如"失物去不远"可套"问题不大、损失有限"；"行人立便至"可套"消息马上到"。

## 4.4 读法提醒：别把六宫当标签

三吉三凶只是大方向，具体吉凶要**看所问何事**：

- 问武职、竞技、"靠是非吃饭"的行当（如诉讼、律师），赤口未必坏；
- 问"求快""求消息"，速喜是好兆；但它"来得快去得快"；
- 小利小吉，大事未必顺；空亡也非一律全凶，各派另有细论；
- 民间还有一句大白话的对照：大安＝稳，留连＝卡，速喜＝快，赤口＝吵，小吉＝小确幸，空亡＝白忙一场。

## 本章要点

- 六宫速览：大安静稳、留连纠缠、速喜快喜、赤口是非、小吉和合、空亡落空。
- 通书版的五行、六神、数字只是**版本之一**；道传、江氏等另有配属，诸说并存（分歧 3/4/6，附录 F）。
- 断辞是活用的韵文，三法变通：名称变通、象数变通、断辞变通。
- 本章所录均为旧时文本与民间说法，非现代建议；健康问题请就医。
