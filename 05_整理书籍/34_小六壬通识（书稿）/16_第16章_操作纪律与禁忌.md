# 第16章　操作纪律与禁忌

> **本章导读**：传统体系除了"怎么算"，还有一整套"什么能算、什么不能算、怎么对待结果"的规矩。这些规矩大部分是民俗约定与行业伦理，不等于科学结论——但它们是理解小六壬文化的重要一面，对今天的使用者也有借鉴价值。

## 16.1 源头性的"三不占"

中国传统卜筮（不限于小六壬）有一条著名的"三不占"：

| 原则 | 含义 |
|---|---|
| **不诚不占** | 心不诚、半信半疑、抱着试探心态，就不要占 |
| **不疑不占** | 没有真正疑惑、靠常识就能判断的事，不要占 |
| **不义不占** | 害人、算计他人、非分之求，不应借占卜求答案 |

江春义版还特别强调**不要"试卦"**——让人算一卦"看看准不准"，被认为是对卦不敬；真正有自尊的从业者不会因此收徒。

## 16.2 八条操作禁忌（各家共识）

1. **遇事即占，无事勿占**——有实际疑惑才起课；"查着玩"、查配偶在干嘛之类，属于滥用；
2. **一事一占，初占为准，再占不灵**——同一件事只占一卦，以第一卦为准；反复占、换时辰再占，是"自己骗自己"；
3. **结果不好也不马上重占**——占到凶卦，不要"下个时辰再占一次安慰自己"；结果不会因重占而改变；
4. **同一时辰通常只占一卦**——掌诀机制下同一时辰重复起课会落回同一格；例外：同一时辰内**互不相识、已隔开时间**的两个人可各占一卦；
5. **起课时机与心态**——最好在心意一动的第一时间、执念最深时起课；不在嬉笑打闹、情绪失控、醉后起课；
6. **数字起课的规矩**——取脑海中浮现的**第一个数字**，不要挑挑选选；心念要对准所问之事；
7. **装卦与断卦要严谨**——装卦先装地支、仔细核对；若解完才发现装错，民间规矩是"错卦错断"、不必重来；断卦要活，不可生搬硬套；
8. **有"不占之事"**——综合民间"算卦七不算"等：
   - 不占**赌博、彩票、炒股投机**；
   - 不测**国运、政治、战争**（现代从业者多明确"完全不碰"）；
   - 不轻易断**生死、寿元**；
   - 不测**胎儿性别**；
   - 涉及**重大疾病、官司、投资**，应找医生、律师等专业人士——占卜不能替代专业意见。

> 第 4 条的两个"官方补丁"：江氏专门设计了**时刻起课**（每 10 分钟一刻）与**数字起课**来破解"同一时辰同卦"的问题；但"一事不二占"始终不变。

## 16.3 问卦者的礼节

1. **想清楚再问**——问题要具体："这个月业绩能不能达标"胜过"我财运如何"；
2. **不要"考考你"**——测试、刁难、隐瞒关键信息，违背"不诚不占"；
3. **不要贪问**——一次问一件最要紧的事；
4. **不问不该问的**——他人的隐私、秘密，未经允许不替人乱占；
5. **拿到答案后**——按信息调整行为，而不是再占一次求心安。

## 16.4 起卦者的守则（从业伦理）

- **不恐吓、不诈财**——不能借"凶卦"吓唬人买化解物品、做法事；
- **不越界**——健康建议就医、法律建议咨询律师、投资建议谨慎；
- **不神化自己**——坦诚流派来源，承认局限；
- **不滥传**——对"祖传秘法""高价课程"保持清醒；
- **保护隐私**——为问卦者保密。

## 16.5 理性视角：把占卜当"镜子"，不当"判决"

几位当代整理者自己给出了最清醒的提醒：

- 中国台湾"馥灵之钥"在教程中坦言：**六个结果、描述模糊，人容易把任何处境套进去**（心理学称"巴纳姆效应"）；小六壬的价值在于"逼你把心里说不清的话掐成一个具体的字，看清此刻处境与选择"，而不是保证命运；
- "**最后做决定的，永远是你自己**"；
- 多个教程页面顶部标注："仅供娱乐，不可作为行为标准"；
- 谨防套路话术："你家老仙不让我看""你身上有不干净的东西"之类，多与恐吓敛财有关。

## 16.6 常见问题精选

| 问题 | 通行回答 |
|---|---|
| 什么时候可以起课？ | 有具体疑问、心意一动时最佳；无事、试探时不宜 |
| 同一件事多久可以再占？ | 各派说法不一（三日／有实际变化后／严格者主张一事一占）；共同点是**不可无变化地反复占** |
| 可以替别人占吗？ | 可以，但最好当事人知情、问题明确；有人开口问事时当场起课最合规矩 |
| 没有农历怎么办？ | 报数法；或查万年历 |
| 晚上能占吗？ | 可以；"夜占留连变数大"属流派说法 |
| 空亡、赤口就一定倒霉吗？ | 不是宿命论——卦象指"当前状态与趋势"，提示宜守宜缓，不是"一定会出事" |
| 能算彩票、股游输赢吗？ | 传统禁忌不主张 |
| 小六壬和大六壬什么关系？ | 同名不同物（第 5 章） |
| 有的教程用年月日时、有的只用日时？ | 流派差异；**选定一家学到底，不要混着套** |
| "活六神"靠谱吗？ | 近现代创新技法、各家不一；初学不必碰（第 13 章） |

## 16.7 各家原话备查

> 江春义《小六壬问卦禁忌》（2011）："占卦一定要心诚……一件事只能占一卦，以第一卦断的事吉凶为准，不能反复的占，反复的占就不灵了。"
> 江阳君（教程 28）："问事起课时，最好是心意一动的第一时间去起课，或是执念最深的时候去起课……同一件事，不要反复的去算。"
> 陈定帮（教学视频）："同一个时辰是不能够这样占的……同一件事你占太多次，根本就是不准确。"
> 民间整理：“遇事即卦，无事莫卦，一事一卦，再占不灵。”

## 本章要点

- 三不占：不诚不占、不疑不占、不义不占；
- 八条禁忌的核心只有两句：**无事不占、一事一占**（含"同一时辰一卦"与"错卦错断"）；
- 从业伦理：不恐吓、不诈财、不越界、保护隐私；
- 理性态度：占卜是"镜子"不是"判决"，决策权始终在自己手里。
