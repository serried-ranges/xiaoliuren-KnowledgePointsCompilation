# 第13章　进阶技法：体用·用神·转太极·具象

> **本章导读**：这是全书技法密度最高的一章，把道传与江氏的进阶工具一次讲完：体用、取用神、转太极、活六神、地支关系、墓库、具象、数字与应期。不必一次消化——先用熟前四节，再按需取用后面的工具。

## 13.1 体用判定：趋势的"修正器"

**以落宫为体，以时辰为用。** 体＝所问之事的结果与状况；用＝未来趋势与外部影响。两者按五行生克对表：

| 关系 | 吉凶 | 含义 |
|---|---|---|
| 用生体 | 大吉 | 外力相助、贵人相助、诸事当成 |
| 体克用 | 小吉 | 主动努力、可成事（"克出"） |
| 体用比助（阴阳不同） | 吉 | 互相帮助、合作相宜 |
| 体生用 | 小凶 | 付出多、消耗大（"生出"） |
| 用克体 | 大凶 | 受阻于外、诸事难成（"克入"） |
| 体用比劫（阴阳相同） | 凶 | 竞争内耗、小人阻碍 |

**演算示例**：

| 落宫 | 时辰 | 关系 | 断 |
|---|---|---|---|
| 速喜（火） | 亥时（水） | 水克火＝用克体 | 不利，事受阻 |
| 速喜（火） | 卯时（木） | 木生火＝用生体 | 有利，贵人相助 |
| 赤口（阳金） | 酉时（阴金） | 同五行、阴阳异＝比助 | 吉，朋友帮手 |
| 赤口（阳金） | 申时（阳金） | 同五行、阴阳同＝比劫 | 凶，竞争内耗 |

**原则**：体用是**趋势修正器，不是吉凶第一来源**——先看落宫吉凶，再用体用修正。若无"后续发展"类的问题，体用可改读为"外部环境对自身的影响"。

## 13.2 六亲与取用神

### 13.2.1 六亲定义

以"我"（身宫）为太极，按五行生克定六亲：

> 生我者父母；我生者子孙；克我者官鬼；我克者妻财；同我者兄弟。

| 六亲 | 类象（江氏） |
|---|---|
| 自身 | 自己 |
| 父母 | 父母、长辈、文化、学习、信息、证件、合同、工作 |
| 兄弟 | 兄弟姐妹、同事同学、竞争、合作 |
| 子孙 | 儿女、晚辈、宠物、货物、能力、财源；也有"解灾之物"的用法 |
| 妻财 | 妻子、女友（男测）、金钱、资金、财产 |
| 官鬼 | 丈夫、男友（女测）、领导、权力；疾病、官司、是非、小人 |

### 13.2.2 江氏用神取法

| 用神 | 适用问题 |
|---|---|
| 父母 | 父母岳父母等长辈；衣物包袱；信息、合同、工作 |
| 兄弟 | 同辈关系（亲属、同学、同事） |
| 子孙 | 子女晚辈、宠物；货物、财源、能力 |
| 妻财 | 男测妻／女友；财运与一切财物 |
| 官鬼 | 女测夫／男友；疾病、官司、纠纷、管制我者 |
| 对宫 | 合作、交易、比赛、官司、借贷、无特殊关系之人 |
| 自身 | 占测自己的事 |

**示例（回到第 10 章的装卦卦例）**：某人农历正月初六戌时问"能不能娶上村长闺女"。装卦后身宫赤口（戌土），六亲分布为：小吉＝妻财（对象）、空亡＝官鬼（阻力／岳父家）、大安＝兄弟（竞争者）、留连＝父母、速喜＝子孙。**取"妻财"为用神**，看它落在小吉、临什么神、与身宫关系如何，再下断——这就是江氏"取用神、一课多断"的基本操作。

> 感情断法另有一个惯例：卦主问"对方的父母"时，看"生天宫的"；若对方自己来问父母，则三宫直接显示，不必转六亲。

### 13.2.3 道传 vs 江氏：一个"转"，一个"装"

- **道传**用"**转太极**"：以落宫为"我"，按需要转出六亲关系（项目生者为获益、生项目者为投资……）；
- **江氏**用"**装六亲**"：把六亲一次性装进六盘，再用"取用神"定位。
- 两者目标相同（回答"这事该看哪一宫"），路径不同——**不要混着操作**。

## 13.3 转太极三类

| 类型 | 什么时候用 | 方法 | 示例 |
|---|---|---|---|
| 六亲转太极 | 问六亲中人 | 以"我"为太极，按生克转出对应六亲 | 落宫示"女"，天宫＝男（姻缘） |
| 事件转太极 | 追问事情相关方 | 按事件前后左右关系转 | 问"项目赚几许"→"生项目者＝获益方" |
| 神煞转太极 | 急变之事、非六亲非事件 | 以六神煞类象转 | 青龙→事业学业；朱雀→文书婚喜 |

**规则**："据需而转，**无问者勿动，无需者勿转**。"——转太极是为了回答"衍生问题"，不是把一课无限拆解。

## 13.4 江氏进阶四技

### 13.4.1 活六神

让六神"离宫移动"来辅助断卦。现见至少两个版本：

- **版本 A（时辰起青龙）**：按时辰排位数，从大安起数到该数，以其落宫为青龙起点，其余顺排。例：午时（第 7 位）→ 大安数 7 仍回大安 → 大安青龙、留连朱雀、速喜勾陈、赤口白虎、小吉玄武、空亡腾蛇；
- **版本 B（落宫神煞起）**：以落宫对应神煞为起点顺时针排，且六神映射本身还有两套。

> ⚠️ **活六神：后起技法，各家不一**——有老手明确表示"并不推荐使用，但也不反对，毕竟是一种创新"。初学建议先按传统六神断法打牢基础（分歧记录见附录 F）。

### 13.4.2 地支择法（给三宫配地支）

- **阴阳规则**：大安、速喜、小吉为阳；留连、赤口、空亡为阴。阳宫落阳位／阴宫落阴位取**阴支**；阳宫落阴位／阴宫落阳位取**阳支**；
- **示例**：大安（阳）—小吉（阳）—空亡（阴），辰时 → 天宫大安取卯、地宫小吉取子、人宫空亡取辰 → 三支为"**卯子辰**"。

### 13.4.3 地支关系速查（断细节用）

**六合**：

| 组合 | 民间含义 |
|---|---|
| 子丑 | 逆合、凑合；先好后坏 |
| 寅亥 | 破合；好中有坏 |
| 卯戌 | 淫合、自焚之象 |
| 辰酉 | 暗合；私下定、不公开 |
| 巳申 | 刑合；在一起就吵、分开又想 |
| 午未 | 明合；公开、实心实意 |

**三合**：申子辰合水、巳酉丑合金、寅午戌合火、亥卯未合木——主和好、合作、团队（半合不如六合旺）。
**六冲**：子午、卯酉、辰戌、丑未、寅申、巳亥——主离散、动荡、矛盾。
**三刑**：寅巳申（争财动官、手足无情）、未丑戌（争权官司、六亲不和）、子卯（口舌伤灾）、辰午酉亥（自刑：自我烦恼、是非）。
**六害**：子未、丑午、寅巳——主六亲不利、脾气、疾病。
**六破**：子酉、寅亥、丑辰、巳申、未戌、卯午——主不成、破裂、从中作梗。

### 13.4.4 墓库应期法

- **辰为水土库、未为木库、丑为金库、戌为火库**；
- 断法："**入库取冲就是应期**"。例：大安—速喜—留连，未时——木入未库，丑未相冲，**丑月**为应期；
- 口诀："**逢刑冲看合，逢合看冲**"。

## 13.5 三宫具象法（高阶）

由三宫阴阳推出一卦（八卦），再论生克得出隐藏细节：

1. **定阴阳**：大安、速喜、小吉＝阳；留连、赤口、空亡＝阴；
2. **取盘序**：天盘按"人—天—地"、地盘按"天—地—人"、人盘按"天—人—地"；
3. **转爻成卦**：三阳为乾、三阴为坤；其余按卦画对应（震、艮、离、坎、兑、巽）；
4. **论生克**（克出／生出／克内／生内／同），**复转三宫**得具象；三盘各得一卦，合断细节。

> **校勘注**：转写本此处曾把巽卦写作"阳阴阴"（与艮重复），按标准卦画巽应为"**阳阳阴·下断**"。使用时以标准卦画为准（此疑误已登记，见附录 F）。
>
> **使用提醒**：具象是"在基本吉凶之上的细化"，**不可推翻基础卦论**；属高级技法，初学可跳过。

## 13.6 数字取数法（断数量、分数、排名）

- **明数**＝宫位排位数（大安 1、留连 2、速喜 3、赤口 4、小吉 5、空亡 6）＋先天八卦数（震巽 4/5、艮坤 7/8、乾兑 1/2、坎 6、离 3）＋河图数（如空亡 5/10）；
- **隐藏数**＝一轮回后继续叠加：大安 7、留连 8、速喜 9、赤口 10、小吉 11、空亡 12；再往上即 1、7、13……2、8、14……以此类推；
- **取法**：考试名次落大安→取 1（第一名）；若需修正，男孩取 4、女孩取 5（"男取阳数、女取阴数"）；
- **原则**："先以卦的吉凶论事，再看数字"；取数要当机立断，犹豫反而不"准"。

## 13.7 应期断法（断时间）

**（一）落宫定季节／地支月**（道传）：

| 宫位 | 季节 | 地支月份 |
|---|---|---|
| 大安 | 春 | 寅、卯（辰）月 |
| 留连 | 四季／长夏 | 辰戌丑未（一说辰巳）月 |
| 速喜 | 夏 | 巳、午（未）月 |
| 赤口 | 秋 | 申、酉（戌）月 |
| 小吉 | 冬 | 亥、子（丑）月 |
| 空亡 | 冬春 | 丑、寅（一说辰戌）月 |

**（二）叠宫位数**：以谋事数／数应取"日、数、人"等具体量；近期以日、时为单位，远期以月、季、年为单位。

**（三）体用与墓库修正**：体用定快慢远近（生者缓、克者急），墓库"入库取冲"定触发点。

**（四）实用提醒**：

- 问考试、面试多取日／时；问婚事、买房多取月／季；问人生大势多取年；
- **给时间范围，不给精确日期**（如"三到七天内""这个季度内"），并说明这只是传统推测。

## 13.8 分类占流程卡（纲要）

道传卜法卷把常见问事归为若干类，各有一套流程：

| 类别 | 流程要点 |
|---|---|
| 成败占 | ①看落宫基本状态 → ②三宫立"顺助／制转／争复／扶孤" → ③合六神类象下断 |
| 婚情占 | ①人宫为核心（成／分／合） → ②天宫＝缘分与对方 → ③地宫＝经过与原因 → ④已婚者转六亲看配偶 |
| 寻物占 | ①先断"能否寻回" → ②天宫＝物之态、地宫＝方位所趋、人宫＝所寻 → ③进阶"转地宫太极"定位 |
| 罹病占 | ①天＝诱因、地＝来去轻重、人＝何病与结果 → ②五行配脏腑 → ③六神修正。（**健康问题请就医，占测不可替代诊疗**） |
| 面相占 | 天＝上停、地＝中停、人＝下停；五行五性（木细瘦、火尖露、金方正、水圆肥、土浊厚） |
| 风水占 | 天＝向、地＝座、人＝入气位；以天宫五行为起点按时辰五行旋转八方 |
| 天象占 | 六神总象（大安阴晴不定、留连细雨、速喜响晴、赤口雷雹、小吉雨脚、空亡阴晦）＋三宫生克气象公式 |

> 以上均为传统体系的**结构化转写**，算法固定、取象灵活；国内整理者的共识是：输出应以"趋势与范围"为限，涉及健康、法律、财务必须回到专业人士。

## 本章要点

- 体用＝趋势修正器：用生体吉、用克体凶、比助吉、比劫凶；**不改落宫的吉凶结果**。
- 六亲取用神是江氏核心：先定"问谁、问什么"，再取对应六亲宫，**一课多断**；道传则以"转太极"实现同类目的。
- 进阶工具按需用：活六神（后起技法、慎用）、地支择法、地支关系、墓库应期。
- 数字有明数与隐藏数两套；应期"给范围不给精确日期"。
