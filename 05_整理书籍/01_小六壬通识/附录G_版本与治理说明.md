## G2. 与治理体系的关系

本书是治理链的**再加工产物**，不改变任何原始材料：

```
互联网原始件 → 01_原始资料（只读）
              → 02_初步处理（机械加工）
              →（按需）03_去封建迷信（对外可用版规则）
              → 04_研究成品（研究文档 00—33＋数据表）
                    └──（通识化重写）→ 05_整理书籍/01_小六壬通识← 本书
```

- 研究层文档**保持原样**；本书是通识化重写的独立产物，2026-10-05 起独立为 **05 整编书籍层**（远端公开层）；
- **注**：01/02/03 为本地治理层，不上传远端；远端仓库仅含 04/05 与根目录治理文件。
- 书中所有结论、案例、数据均可回溯到研究层对应文档与来源编号；
- 引用本书时，请连同**版本日期**一并注明。

## G3. 撰写体例

- **由浅入深**：第一编入门 → 第七编研究，分层递进；
- **去治理化表述**：正文不出现"本包/版本戳"等档案语（档案信息集中在本附录）；
- **分歧标注**：正文 ⚠️ 分歧框＋第 23 章总录＋附录 F 索引（同一编号体系）；
- **来源标注**：各章章末注明主要依据；来源编号沿用附录 E；
- **目录跳转**：扉页总目录链接各章文件；合订本内为**章级锚点**（`<a name="chNN">` / `appX`）文档内跳转，章末设"↑ 返回目录"（锚点 `top`）；
- **案例伦理**：全部案例注明"自证型、不作准确率证据"；健康/法律/财务附专业提示。

## G5. 审计与自查

- 每轮写作后执行：政治合规扫描＋内容敏感词扫描（六类词）＋交叉引用自查；
- 结果逐轮记录于《书稿审计记录》；研究层双审计脚本（`audit.js`／`content_audit.js`）已扩展覆盖本书稿目录（现指向 `05_整理书籍/`；元文档与合订本除外），每轮更新后运行；
- 门禁口径：**收录≠采信**；C 级内容只作历史与民俗记录。

## G6. 更新约定

1. 新资料先进入治理层 01（登记）→ 02（机械加工）；
2. 研究结论更新至 04 层对应文档；
3. 本书按编同步修订，并在《书稿审计记录》中留痕；
4. 重大修订（结构级）升书稿小版本；勘误级在合订本"修订记录"中列出；
5. 涉及"待核"事项出现实物证据时，优先修订第 7、9、26 章与附录 F；
6. 内容修订后：运行 `_工具_生成PDF.js`（自动重建合订本＋PDF）→ 跑双审计 → 记录（流程详见《_工具_PDF生成说明.md》）。
