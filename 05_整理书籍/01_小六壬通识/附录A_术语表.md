# 附录 A　术语表

> 读古籍、教程时的"名词障碍"一站解决。分类：A 基础概念｜B 道传/江氏专有｜C 历史/文献｜D 现代/心理。

## A. 基础概念

| 术语 | 释义 |
|---|---|
| **小六壬** | 又称六壬时课、诸葛马前课、掐指一算；民间掌诀占法，六宫循环。 |
| **六宫 / 六神 / 六煞** | 大安、留连、速喜、赤口、小吉、空亡六个固定宫位；或称"六神""六煞"。 |
| **掌诀** | 把推算规律简化为掌上位置与口诀的"手上算法"，又称掐指。 |
| **起课 / 起卦 / 装卦 / 排卦** | 得到卦（落宫、卦盘）的全过程；江氏把"排地支/六亲/六神/五星"叫装卦。 |
| **落宫** | 掐算后最后停下的宫位；传统以时宫（落宫）为结果，道传以落宫为"体"。 |
| **三宫 / 三盘** | 月宫、日宫、时宫；或称天盘、地盘、人盘。 |
| **用神** | 卦中代表"所问之事"的那组信息（宫、六亲、六神等）；"取用神"即确定它。 |
| **体 / 用** | 道传：落宫为体（结果/自身状况），时辰为用（未来趋势/外力）。 |
| **六亲** | 父母、兄弟、子孙、妻财、官鬼（＋自身）；由五行生克推演。 |
| **五行** | 金木水火土；相生相克是断卦基础。 |
| **旺相休囚死** | 五行在不同季节的力量状态。 |
| **六十甲子** | 天干与地支相配的六十循环；小六壬一般只用十二地支。 |
| **十二地支** | 子丑寅卯辰巳午未申酉戌亥；配十二时辰。 |
| **十二时辰** | 子时 23—1 点、丑时 1—3 点……每时辰 2 小时。 |
| **应期** | 所问之事的应验期限（何时发生）。 |
| **外应** | 起卦时看到的"不寻常现象"（声音、颜色、物件等），作判断参考。 |
| **错卦错断** | 若解完卦才发现卦装错，就按错的卦断——民间认为"天意如此"。 |

## B. 道传 / 江氏专有

| 术语 | 释义 |
|---|---|
| **道传小六壬 / 道家小六壬** | 当代邵一尘所传体系：三宫（天地人）＋时辰，含体用、转太极等；对外称"十二卷"。 |
| **江氏小六壬** | 江春义（江阳君）所传体系：六宫＋十二地支＋六亲＋六神＋五星，可一课多断。 |
| **四盘** | 江氏：六宫＝地盘、六亲＝人盘、六神＝神盘、五星＝天盘。 |
| **身宫** | 江氏：时辰所落之宫，代表卦主自身；以它定六亲。 |
| **装地支** | 江氏：以时辰地支落宫为准，顺时针"隔位排"地支。 |
| **隔位排** | 排地支时跳过中间的一个地支（如戌→子→寅→辰……）。 |
| **五星 / 六星 / 天空** | 江氏辅助盘：木火土金水＋"空"共六位；从日落宫起木星顺排。 |
| **转太极** | 以某一点为"我"重新旋转推演（六亲/事件/神煞三类）。 |
| **三宫具象** | 道传高级技法：由三宫阴阳定八卦，再论生克"具象"。 |
| **活六神** | 近现代创新技法：让六神按规则"移动"辅助断卦（各家不一）。 |
| **地支择法** | 按三宫阴阳规则给三宫配地支。 |
| **墓库应期** | 辰水土库、未木库、丑金库、戌火库；"入库取冲为应期；逢刑冲看合，逢合看冲"。 |
| **天时之法** | 道传自称：以三才成卦、以天地人三盘断事。 |
| **本气法 / 借气法** | 道传概念：靠修持感应（本气）与靠理论推演（借气）两类路径（体系自述）。 |

## C. 历史 / 文献

| 术语 | 释义 |
|---|---|
| **六壬** | 大六壬之名；得名诸说（河图阳水、六个壬干等）。 |
| **大六壬 / 中六壬 / 小六壬** | 大六壬＝三式之一；中六壬＝天罡掌诀（霍斐然说）；小六壬＝本书主题。 |
| **马前课** | ①小六壬俗称；②托名诸葛亮的十四课谶诗（两种含义要分清）。 |
| **六壬时课** | 《玉匣记》中所载小六壬的名称（全称"李淳风六壬时课"）。 |
| **六曜 / 六辉** | 中国六名系统；日本演变为先胜、友引、先负、佛灭、大安、赤口。 |
| **玉匣记** | 《增补许真君万全玉匣记》，小六壬的主要传世载体。 |
| **上兀下兀日** | 宋代择日神煞；《协纪辨方书》称"即俗传小六壬之留连、赤口日"。 |
| **兀法 / 六轮兀法 / 本命兀法** | 宋元择日法；沈括修《元丰历》选用"六轮兀"；本命兀是个人定制版。 |
| **六轮经** | ①宋代择日法（兀法）；②清代江浙丧葬"批书"的另一种同名物（勿混）。 |
| **龙母决** | 敦煌 P.3803 中与小六壬轮布相同的雏形记载。 |
| **协纪辨方书** | 清乾隆四年（1739）敕撰；批评"小六壬"用日法"尤为荒陋"。 |
| **宿曜经** | 唐不空译（759）、杨景风注的密教占星经；六曜可能的远源之一。 |
| **天罡掌诀** | 托名诸葛亮的"中六壬"；霍斐然 1976 年得本、1997 年整理。 |
| **一掌经** | 托名唐一行的掌上命理；与道传"六道十二宫"相关。 |

## D. 现代 / 心理

| 术语 | 释义 |
|---|---|
| **巴纳姆效应** | 人容易把模糊、普遍的描述当作"说中自己"；六宫断语极易触发。 |
| **确认偏误** | 只记住"应验"案例、忽略失准案例的倾向。 |
| **决策投射工具** | 部分现代平台的自我定位：不保证命运，只帮你把心事投影成具体意象。 |
| **三不占** | 不诚不占、不疑（无疑）不占、不义不占。 |
| **算卦七不算** | 民间行业禁忌（生死寿元、胎儿性别等），属伦理惯例。 |
