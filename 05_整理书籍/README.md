# 05 整理书籍

> 本目录＝**整编书籍层**：存放由 04 研究成品层**通识化重写**的书籍产品（书稿、合订本、PDF 与生成工具）。

## 内容

> 命名约定：`NN_书名`（NN 为层内序号，为后续书籍预留编号）。

- `01_小六壬通识/` —— **《小六壬通识：源流·体系·诸派》**（34 章＋附录 A—G）
  - 分章 md（扉页总目录带跳转链接）｜合订本 md（带章级锚点，可在文档内跳转）｜合订本 PDF（约 148 页：**目录逐章页码＋页脚页码＋书签目录**）
  - 生成工具：`_工具_生成合订本.js`｜`_工具_生成PDF.js`（＋`.bat`）｜排版库 `_工具_paged.polyfill.js`（MIT）｜方案文档 `_工具_PDF生成说明.md`
  - 书稿审计记录（7 轮写作自检＋收尾轮＋增补轮）

## 一键重新生成

```
node "01_小六壬通识/_工具_生成PDF.js"
```

（自动：重建合订本 → 转 HTML → Edge/Chrome 无头打印 PDF；Windows 下也可双击 `_工具_生成PDF.bat`。）
