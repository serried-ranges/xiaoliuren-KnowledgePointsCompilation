# 重建脚本说明（02层·工具）

> 用途：从 01 层原始件**重建 02 层产物**（文本提取、索引、登记表）。全部脚本为 Node.js（无第三方依赖的用 `node xxx.js` 直接跑）。
> 运行环境：Node.js ≥ 18。运行目录：将 01 层相关文件置于脚本同目录（或按脚本内路径调整）。

| 脚本 | 作用 | 输入 → 输出 |
|---|---|---|
| `jyj_extract_all.js` | 江阳君教程页 → 纯文本 | `jyj_post_*.html` → `jyj_txt/` ＋ `jyj_index.csv` |
| `jyj_cases.js` | 教程案例字段提取 | `jyj_txt/` → `jyj_cases.csv` ＋ `jyj_cases.md` |
| `jyj_pack_md.js` | 案例索引成稿 | `jyj_cases.csv` → 《24_附表》md |
| `jyj_premium.js` | 30篇精编成稿 | `jyj_txt/` → 《27 精编》md |
| `jcy_extract.js` | 江春义文章 → 纯文本（第1批） | `jcy_post_*.html` → `jcy_txt/` |
| `jcy_extract2.js` | 江春义文章 → 纯文本（第2批） | `jcy_myz*.html` 等 → `jcy_txt/` |
| `jyj_parse.js` | 单页正文解析（调试用） | 单个 html → 控制台 |
| `gov_registry.js` | 原始层来源登记表生成 | 01层文件名 → `来源登记表.csv` |
| `extract.js` | PDF → 全文（需 `npm i pdf-parse`） | pdf → txt |

> 备注：影印渲染/OCR 类脚本（pdf-to-img / tesseract.js / @napi-rs/canvas）因需额外依赖，未随包；如需请另行安装依赖后重建。
> 审计脚本在 04 层《附录·审计工具（脚本）》内（audit.js / content_audit.js）。

*本说明随治理层维护。*
