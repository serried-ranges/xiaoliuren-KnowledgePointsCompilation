## 一、仓库结构（治理体系）

```
├── 00_治理说明（架构·规则·长期计划）.md
├── README.md（本文件）
├── 01_原始资料\      ← 第一层：互联网原始件
├── 02_初步处理\      ← 第二层：机械加工产物
├── 03_去封建迷信\    ← 第三层：按门禁生成的对外可用版
└── 04_研究成品\      ← 第四层：研究文档汇编
```

**各层含义（层名已不带说明，在此集中阐述）**：

- **01_原始资料**：互联网抓取的原件（HTML/PDF/影像），**只读、永不修改**，保留全部缺陷；含《来源登记表.csv》。
- **02_初步处理**：机械化加工产物（文本提取、索引、审计记录、重建脚本），**不做解释**、可随时从01层重建。
- **03_去封建迷信**：按 A/B/C/D 门禁降权清理后的"**对外可用版**"，**按需生成、每处留痕**。
- **04_研究成品**：研究文档 00—32 ＋ 4个数据表 ＋ 附属件（影印/核对件/双审计工具），**基于治理链生成**。

## 三、治理原则

1. **不早处理**：原始层只读；初步层只做机械加工；去迷信层按需生成。
2. **三层隔离**：原始/初步/去迷信物理分离，互不覆盖。
3. **可追溯**：来源登记表＋处理留痕；正文引用均可回溯。
4. **双审计**：每轮更新后运行结构审计＋内容审计（脚本见 04 层"附录·审计工具"）。

## 四、内容采信分级（门禁）

| 级别 | 含义 | 处理 |
|---|---|---|
| A | 文献原文/实物影像/可核事实 | 正常引用 |
| B | 体系自述、公开教程与案例 | 可引用为"该体系称…" |
| C | 民俗信仰/神通符咒/恐吓断辞 | **仅存档、不采信**；显著标注 |
| D | 营销/低质/无法溯源 | 不收录 |

> **收录≠采信**：C级内容作为民俗文本保留原貌，不代表其效力被认可。
