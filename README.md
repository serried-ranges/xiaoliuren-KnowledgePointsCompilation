## 发布流程

1. 将新来源登记到本地原始层，记录作者、版本、日期、原文位置和许可信息。
2. 区分古籍文本、作者自述、二手研究、第三方传播件和项目分析。
3. 逐项核对来源、许可对象及适用范围；未核内容仅保留必要书目线索。
4. 更新来源状态表、研究文档、书稿、目录和发布日志。
5. 生成合订本与 PDF，运行结构审计和内容审计，并由人工/第二人复核命中项及许可范围。
6. 提交后检查远端镜像是否到达同一提交。

## 审计与使用提示

结构审计使用 04_研究成品/附录·审计工具/audit.js，检查索引、编号、引用与书稿结构；内容审计使用 content_audit.js 扫描敏感词并由人工判断语境。两项均完成且人工复核后才发布。

本项目定位于传统文献与民俗研究。内容不构成医疗、法律、投资或其他专业建议，也不验证或背书预测效力。
