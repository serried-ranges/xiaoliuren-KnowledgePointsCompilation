## 一、仓库结构（治理体系）

```
├── 00_治理说明（架构·规则·长期计划）.md
├── README.md（本文件）
├── .github\          ← GitHub Actions 自动镜像（mirror.yml）
├── 01_原始资料\      ← 第一层：互联网原始件（本地，不上传）
├── 02_初步处理\      ← 第二层：机械加工产物（本地，不上传）
├── 03_去封建迷信\    ← 第三层：对外可用版（本地，不上传）
├── 04_研究成品\      ← 第四层：研究文档汇编（公开）
```

> **双轨说明**：01—03 层由 `.gitignore` 排除、不进入 git；远端可见内容＝04＋05＋根目录文件。原始材料仍在本机按治理流程积累（详见《00_治理说明》第七节）。

**各层含义（层名已不带说明，在此集中阐述）**：

- **01_原始资料**：互联网抓取的原件（HTML/PDF/影像），**只读、永不修改**，保留全部缺陷；含《来源登记表.csv》。**（本地层）**

- **03_去封建迷信**：按 A/B/C/D 门禁降权清理后的"**对外可用版**"，**按需生成、每处留痕**。**（本地层）**
- **04_研究成品**：研究文档 00—33 ＋ 4个数据表 ＋ 附属件（影印/核对件/双审计工具），**基于治理链生成**。**（公开）**
- **05_整理书籍**：整编书籍层——**《小六壬通识：源流·体系·诸派》**（35 章＋附录 A—G；含合订本 md/PDF、生成工具与书稿审计记录），**由 04 层研究文档通识化重写**。**（公开）**

## 三、治理原则

1. **不早处理**：原始层只读；初步层只做机械加工；去迷信层按需生成。
2. **三层隔离**：原始/初步/去迷信物理分离，互不覆盖；**且不上传远端**（本地双轨制）。
3. **可追溯**：来源登记表＋处理留痕；正文引用均可回溯（公开层保留来源清单与编号）。
4. **双审计**：每轮更新后运行结构审计＋内容审计（脚本见 04 层"附录·审计工具"，书稿目录一并覆盖）。

## 四、内容采信分级（门禁）

> **政治原则优先（一票否决）**：坚持一个中国原则；涉台/涉港/涉澳表述一律规范化（中国台湾／台湾地区、中国香港、中国澳门等）；不涉及政治与国运内容。规则见 04 层《32》§〇。

| 级别 | 含义 | 处理 |
|---|---|---|
| A | 文献原文/实物影像/可核事实 | 正常引用 |
| B | 体系自述、公开教程与案例 | 可引用为"该体系称…" |
| C | 民俗信仰/神通符咒/恐吓辞 | **仅存档、不采信**；显著标注 |
| D | 营销/低质/无法溯源 | 不收录 |

> **收录≠采信**：C级内容作为民俗文本保留原貌，不代表其效力被认可。
