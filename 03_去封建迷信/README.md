# 03 去封建迷信· 层说明

> 本层＝按需生成的"**对外可用版**"：把 02 层材料按知识包《32 内容审计与采信门禁》的 **A/B/C/D 分级**做降权/清理。
> **不早处理原则**：默认**不批量生成**；只在某个材料明确需要对外发布、引用、教学时，才为它单独制作本层版本。

## 处理动作定义（按分级）

| 分级 | 处理动作 | 输出形态 |
|---|---|---|
| **A**（文献/实物/可核事实） | **保留** | 原文引用（带出处） |
| **B**（体系自述/教程/案例） | **保留＋语境化** | 表述为"该体系称…/据其教程…"，不作效力断言 |
| **C**（民俗信仰/神通符咒/恐吓断辞） | **降权改写（墓碑化）** | 去除操作细节与效力宣称，仅留：文献名、体例、结构、历史语境、来源；不含"怎么做" |
| **D**（营销/垃圾/无法溯源） | **不收录** | 仅在说明中注明"已忽略" |

## 留痕规范（每条改动必须可回溯）

```
来源条目（01/02层文件） → 分级判据（《32》条目号） → 动作（保留/语境化/降权/忽略） → 处理后文件
```

- 每条处理写进对应导出文件的"处理记录"表；
- 若同一材料多处涉及C级，逐处记录，不合并省略。

## 红线（对外版强制，一票否决）

1. **政治原则（最高优先级）**：坚持一个中国原则——涉台/涉港/涉澳表述一律规范化（中国台湾／台湾地区、中国香港、中国澳门等）；机构名用规范称谓（如台北故宫博物院）；不得出现任何分裂国家、损害国家主权和领土完整的内容（规则见《32》§〇）。
