1. **只读**：本层文件已设只读属性；如需更新，先解除只读→修改→再设只读，并在登记表注明变更。

3. **登记**：新增文件必须补录《来源登记表.csv》（URL/日期/备注），无登记视为未完成入库。
4. **禁止**：在本层直接做文本替换、删广告、改错别字、去迷信——那是02/03层的事。
