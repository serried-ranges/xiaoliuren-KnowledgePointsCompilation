# 05 书籍整理

> 本目录＝治理体系的 **书籍整理层（公开）**：存放**第三方源书**（原书 PDF）及其**整理文档**。
> 组织方式：**一本 PDF 一个文件夹**——PDF 直接放在本层根下，整理文档放在**同名文件夹**里。

## 结构

```
05_书籍整理/
├── <书名>.pdf                 ← 第三方原书 PDF（外层）
├── <书名>/                    ← 该书的整理文档（同名文件夹）
│   └── …（全文提取/结构化/索引/识读稿等）
├── 其他（无对应PDF）/          ← 暂无 PDF 的整理件（如网页/论坛来源）
└── README.md
```
